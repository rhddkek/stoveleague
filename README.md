# 스토브리그 — 작은 구단의 기적

가상 야구 구단을 맡아 유망주를 발굴·육성·판매하고, 승강제를 거쳐 1부와 해외 무대까지 키워 가는 싱글플레이 구단 경영 게임입니다.
결과물은 HTML 파일 하나(`stoveleague.html`, 같은 내용 `index.html`)이며 서버 없이 브라우저에서 바로 실행됩니다.

- **플레이**: https://rhddkek.github.io/stoveleague/ (테스트 모드 `?test=1`)
- **GPT·Claude 공동 작업**: [`review/README.md`](review/README.md) · 상태판 [`review/STATUS.md`](review/STATUS.md)

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `src/core_a.js` | 상수(BAL)·이름·구단 목록·선수 생성·능력치·라인업 |
| `src/core_b.js` | 경기 엔진 (투구 단위, 모든 진행 버튼이 같은 엔진 사용) |
| `src/core_c.js` | 시즌·성장·이적·FA·드래프트·해외 리그·파견·감독 평판/이직·코치진·저장/변환 |
| `src/ui.js`, `src/style.css` | 화면 (모바일 우선, 960px 이상 PC 좌우 배치) |
| `assets/` | 픽셀 초상화·구단 엠블럼·구장(Pixellab), 효과음(ElevenLabs; `sfx_raw`는 원본) |
| `build.js` | 위 파일을 합쳐 `stoveleague.html`(배포용)과 `stoveleague_artifact.html`(Claude 아티팩트용) 생성 |
| `test/` | 자동 검증과 구버전 세이브 샘플 |
| `src_v1`·`src_v2`·`src_v3` | 구버전 코드 스냅숏 — 구버전 세이브 샘플을 다시 만들 때만 사용 |

## 빌드·검증

```bash
npm install          # jsdom (화면 테스트용)
npm run build        # stoveleague.html 생성
npm test             # 빌드 후 전체 검증
```

| 테스트 | 확인 내용 |
|---|---|
| `verify.js <시드> <시즌>` | 10시즌 자동 진행: 로스터·소속 무결성, 일정, 결정성, 경기 중 저장·재개, 이적 거래 |
| `phase1.js` | 해외 리그·겨울리그 파견·성장 중복 방지·15시즌 장기 진행 |
| `phase2.js` | 감독 평판·이직·복귀·옛 제자, 주전 대량 매각 평판 악용 방지, v1/v2 세이브 변환 |
| `leagues.js` | 해외 리그 실제 규모(일본 12·미국 30·대만 6·멕시코 20·호주 4·도미니카 6), 지구별 순위, v3 세이브 변환(일본 감독 시즌 중 포함) |
| `staff.js` | 코치진 효과·계약·해임·재계약·인건비·저장 |
| `story.js` | 정보 신뢰성·구단 유형·이야기/보고서/결산·겨울 휴식·출신 코치·감독 제의 이유 |
| `ui_smoke.js` | jsdom으로 실제 화면 클릭 흐름 |
| `ui_layout.js` | Playwright 360px 폰 화면: 가로 넘침·하단 메뉴 가림·주요 흐름 (Playwright 없으면 건너뜀) |

## 고정 규칙

- 실존 선수·구단명·로고를 쓰지 않는다. 해외 리그 이름·규모는 실제를 따르되 구단은 「실제 연고 도시 + 가상 애칭」.
- 선수는 국가·리그를 옮겨도 같은 ID로 기록·관계(옛 제자·셀온)가 유지된다.
- 이적은 돈·소속·계약을 한 번에 처리한다.
- 시즌 성장·동계훈련·겨울리그 파견 성장은 겹치지 않는다(파견 시 동계훈련 대체).
- 저장 형식을 바꾸면 `VERSION`을 올리고 `migrate()`에 변환을 넣으며, 구버전 세이브 샘플로 검증한다. 변환 실패 시 원래 상태를 보존한다.
- 수정 후에는 `npm test`가 전부 통과해야 배포한다.
