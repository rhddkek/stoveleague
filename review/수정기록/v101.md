# v101 수정기록 — 몸값·예산 현실화 + 샐러리캡(경쟁균형세) (R084-1·2)

- v101은 v102와 함께 냈습니다(게임 표시 번호는 v102). 검사 파일 `test/v101_r084.js`
- 세이브 형식 그대로(VERSION 6). 새 값 `S.moneyV`(금액 변환 표시)·구단 `capHist`·`capOver`·`capUnder`·`capPen`·계약 `cb`(계약금 ÷ 연수) — 없으면 자동으로 채움
- **방식**: 내부 금액 단위를 「1 = 5만원」으로 바꿈(`BAL.WON`). 화면의 모든 금액(`money()`·`Ms()`)이 ×5로 보입니다. 수입·지출·연봉·몸값·예산이 **같은 비율로** 커지므로 구단 살림(흑자·적자 구조)과 AI 밸런스는 그대로이고, 예전 저장도 그대로 이어집니다
- 같은 비율로 키우면 실제와 어긋나는 곳만 따로 맞춤: 최저 연봉 · 아시아쿼터 상한 · 신규 외국인 상한 · 신인 계약금
- npm test 41종 전체 통과

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| R084-1 금액 현실화 | 반영 | 새 게임 → 선수단 → 선수 연봉: 주전급 2~30억, 2군 3,000만~1억. 이적 → 선수 찾기 → FA 「연봉 1억/3억/10억 이하」 필터. 구단 → 재정 → 예산관리 「이적 15억 → 연봉 5억」 |
| R084-1 최저 연봉 | 반영 | 첫 시즌 국내 선수 최저 3,000만, 2시즌(2027년)이 되면 모든 계약 3,300만 이상 |
| R084-1 외국인 상한 | 반영 | 새 외국인 협상에서 연봉+계약금 14억 넘게 제시 → 「신규 외국인 선수 계약 상한 14억원」. 아시아쿼터 자리는 2.8억 이하 |
| R084-1 협상 입력칸 | 반영 | 협상 표 아래 「샐러리캡 ○억 → ○억 / 상한 144억」 줄. 숫자 입력칸은 만원 단위 |
| R084-1 예전 저장 | 반영 | v100 이전 저장을 불러오면 소식 「[구단 운영] 금액이 실제 KBO 규모로 바뀌었습니다 — 모든 금액 ×5 …」. 구단 자금이 예전 화면의 5배로 보임. 최저 연봉 밑이던 선수만 조정 |
| R084-2 샐러리캡 | 반영 | 구단 → 재정 → 쪽 「샐러리캡」: 우리 상위 40명 합계·상한 144억(2026)·여유, 10개 구단 표. 상한은 시즌마다 +5% (2027 151억). 하한(2027년부터 61억) 안내 |
| R084-2 초과 제재 | 반영 | 상한을 넘긴 채 시즌이 끝나면 소식 「[경쟁균형세] ○○ ○억 납부 — 상위 40명 연봉 … 넘음 (1회 연속 → 30%)」, 재정 표 「⚖ 경쟁균형세(샐러리캡)」. 2회 연속 50% · 3회 연속 100% + 다음 드래프트 1라운드 지명 9단계 하락. 하한 밑이면 모자란 금액에 같은 비율 |
| R084-2 AI 구단 | 반영 | AI는 상한을 넘기는 FA 입찰·영입·재계약(핵심 선수 빼고)을 하지 않음. 트레이드도 AI가 상한을 넘게 되면 「샐러리캡을 넘게 됩니다」로 거절 |
