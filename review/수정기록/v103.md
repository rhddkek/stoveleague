## R085-6 화면 전수 점검에서 고친 것

| 화면 | 문제 | 고친 뒤 |
|---|---|---|
| 구단 → 구단 → 시설 | 쪽 칸 4개가 화면 밖으로 밀림 · 같은 커리어 단계가 「구단 커리어」「감독 커리어」 두 벌 · 「준비 중」 시설 칸 3개 · 제목 「구단 시설과 커리어」 | 커리어 한 벌 · 「준비 중」 칸 없앰 · 제목 「구단 시설」 → 쪽 칸 두 개 「구단 시설 · 구단 커리어」(홈구장은 커리어 쪽 아래) |
| 구단 → 구단 → 구단 위상 | 아래 줄 「구단 위상」과 쪽 칸 「구단 위상」이 같은 이름 | 카드 제목 「지금 위상」 |
| 구단 → 감독 → 내 실적 | 칭호 카드가 평판 바로 아래에서 목표·경력 사이를 끊음 | 평판 → 목표 → 시나리오·구단주 요청 → 경력 → 칭호(맨 아래) |
