## 화면별

| 화면 | 바꾼 것 | GPT가 확인할 방법 |
|---|---|---|
| 재계약 (이적 → 계약 관리 → 재계약, 겨울) | 표 = 선수(자리·능력·나이) · 역할 · 현재 → 요구(↑↓) · 결정. 이름 아래 계산식(능력 −1 · 현 연봉+5% …) 없앰 → **금액을 누르면 「요구액 근거」 창**. 결정은 줄에서 바로 **[수락][협상][결별]** (선수마다 창을 열지 않음). 아래 「수락 n · 협상 n · 결별 n · 미정 n · 연봉 +○ · 추가 연봉 한도 ○ → ○」 + **[추천 선택] [전원 수락] [선택 적용]** | 겨울 1주차 재계약 화면 |
| 훈련·성장 | 육성 위 줄 「훈련·성장」 → **「훈련」·「성장」** 두 칸 (안쪽 「훈련 설정 | 성장정보」 칩 줄·「주간 훈련 설정」 제목·사용 설명 없앰). 훈련 화면 = 「훈련 · n주차」 → 강도 → [전체][유망주][투수][야수]. 표 머리 **포지션 · 선수 · 훈련 · 시즌 성장 · 피로** — 시즌 성장은 개막(입단) 뒤 실제 종합 변화, 기록이 없으면 「-」, 0이면 「—」 (예전엔 기록이 없을 때 나이로 짐작한 값을 「변화(예상)」으로 보였음). 아래 상세 「현재 / 예상」, 「주간 목표 · 제구 +3」, 단추 「훈련 적용」. 「성장」 탭 = 성장 기록 | 육성 → 훈련 / 성장 |
| 겨울리그 (육성 → 겨울리그) | 머리 「파견 n/4 · 2주차 마감」, 긴 설명은 「방식 비교 ⓘ」 안. 선수 줄 = 「서승준 RP · 62 / 추천 파견지 시드니 · 주전 / 비용 1.5억 · 성장 국내보다 유리」 + **[파견] [다른 구단]** | 겨울 1~2주차 |
| 파견지 화면 | 「겨울 계획 [국내 훈련][해외 파견][휴식]」(지금 고른 칸 하나만 켜짐) + 「방식 비교 ⓘ」 접힘. 해외 파견일 때만 「파견 구단」 목록: 리그 · 선수 수준 · 성장 · 비용. 「복귀 시 피로 · 컨디션」 한 줄. 성장 이름 **국내보다 유리 / 국내와 비슷 / 국내보다 불리**, 「리그 수준 미달」 → **「선수 수준 부족」** | [다른 구단] |
| 재정 (구단 → 재정) | 돈 이름 **보유 현금 · 영입 예산 · 추가 연봉 한도**(위 줄은 「영입 예산 · 연봉 한도」). 예산 조정: 「연봉 한도 늘리기 / 영입 예산 늘리기」 → **영입 예산 −15억 · 추가 연봉 한도 +5억** 크게, 바뀐 뒤 잔액, 「묶음 ×1 · 전환 가능 3회」. 위 세 칸 = 보유 현금 · 영입 예산 · 연봉 예산(사용/예산) + 막대 하나(사용률 · 추가 가능) — 같은 금액 네 번 → 한 번, 「예산 산정 기준 ⓘ」 접힘. 샐러리캡은 **지금 상태 먼저**: 「상한 초과 · ○ / 연봉 하한 미달 · ○ 부족 / 상한까지 ○」 + 「산정액 ○ / 상한(하한) ○ · 지금 계약 기준」, 「규정 ⓘ」·「다른 구단 비교」 접힘, 「2027 정산」. 「확정 지출」 = 시즌 · 계약 인원 · 총연봉 (같은 금액 두 칸이던 보장액 칸 뺌). 「수입·지출」 · 「선수 연봉」 · 「운영비 (시설·스카우트·코치·파견)」 · 「전년 대비」 | 구단 → 재정 쪽 칸 4개 |
| 시설 | 「구단 시설 · 시설 점수 52」 → 시설 세 칸 → **「훈련장 증설 · Lv.1 → 2」** 한 제목에 **성장 보너스 0% → 12% · 일일 회복 14 → 16** · 「증설비 10억 · 시즌 유지비 ○」 · **[증설 · 10억]**. 커리어 목표(첫 시즌 완주 → … 명예의 전당)는 시설 화면에서 빼고 감독실 커리어 띠에만 | 구단 → 구단 → 시설 |
| 스폰서·광고 | 메인 스폰서 「시즌당 ○ · 고정」·「기본 계약 1년」. 광고판 줄 「고정 · 11.8억 / 관중 연동 · 예상 11.7억」(입장 수입 몇 %는 ⓘ 설명에). 「광고판 공석」·「광고 선수 없음」. 인기 점수 나열 대신 **「광고 제안 가능 n명 (제안 도착은 위) [선수 보기]」** → 창에 인기 점수와 기준 | 구단 → 스폰서·광고 |
| 트레이드 | 「구단별 수요」(설명 부제 뺌) · 「보강 포지션」 · 「트레이드 매물 [교환 후보 추가]」 · 「우리 매물」(없으면 「등록 매물 없음 [매물 등록]」) · 「리빌딩 · 베테랑 저평가」. 선수 교환: 표 꼬리표 **상대 관심 · 핵심 전력**, 빈칸 「-」 여섯 개 → 양쪽 **「보낼 선수 / 받을 선수 ＋ 선수 선택」** 한 칸, 「추가 지급」, 고르기 전엔 「교환 조건」 줄 없음, 단추 **상세정보 · 선택 해제 · 교환 제안** | 이적 → 트레이드 |
| 국내 스카우트 | 「해외 스카우트 ›」 바로가기(설명 문장 대신) · 대상 「지역 유망주 · FA · 다른 구단」 · 「검색 조건」 · 「현재 등급: 전체」「잠재력: 전체」「나이 상한」「가치 상한(만원)」 · 「조사 수준 ⓘ · 하루 2회」 · 단추 **「조사 시작 · 4,000만」**(고른 수준 비용) | 이적 → 발굴 → 국내 스카우트 |
| 유소년 | 「입단 후보 · 개막 전 계약 · 미계약 시 이탈」 · 「요구 연봉 ○」. **투수에게 타격 특성(장타본능·빠른발)을 보이지 않음** — 투수는 타석에 서지 않아 효과가 없음(특성 자체·계산은 그대로) | 겨울 → 유소년 |
