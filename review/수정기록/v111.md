## 1. 신뢰 — 서로 맞지 않는 표현 · 비용 변화 설명

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 관찰 전 34.8억 → 관찰 뒤 118억을 이전 화면과 비교해야 앎 | 반영 | 해외 선수에게 「집중 관찰」 → 2주 뒤 스카우트 보고서 맨 위 **「관찰 전과 달라진 점」**: `비용 상승 · 34.8억 → 118억` / `미국 2군 → 미국 1군 승격 · 이적료 20.8억 → 104억 (1군 선수는 이적료 기준이 높음)` / `평가 조정 · 1선발 후보 → 2선발 후보 · 지식 12% → 100%`. 이유는 엔진에서 실제로 바뀐 것만 씀: 소속 변경 · 1군 승격/강등(이적료 계산이 1군 0.6배 · 하부 0.12배로 다름) · 연봉 시세 변화 · 선수 가치 변화. 바뀐 게 없으면 칸이 안 나옴. 재현: 시드 4096 · 9번 구단 · 미겔 오르티스 |
| 관찰 예고 12% → 50%, 완료 100% | 반영 | 버튼이 실제 계산(주당 상승 × 남은 주)으로 **「지식 12% → 88% 이상」**. 「이상」인 이유: 관찰 중 1군으로 승격되면 소속 정보가 늘어 더 오름(오르티스는 그래서 100%). 관찰 중 버튼 「관찰 중 · 1주 남음 · 지식 → 88% 이상」 |
| 관찰 버튼은 「강점·약점 공개」인데 보고서는 이미 강점·우려 표시 | 반영 | 보고서 칸 이름 **「강점 · 초기 추정」 / 「강점 · 관찰 확인」**(지식 60% 이상). 버튼 설명은 「능력 범위 좁힘 / 강점·우려 확인 / 능력·강점 확정」 |
| 확정 능력 72–72 | 반영 | 범위가 한 값이면 한 숫자(72). 보고서·해외 목록·선수 화면·협상 화면 공통 |
| 주요 기록(없음) 안에 다시 「기록 없음」 | 반영 | 기록이 없으면 칸 자체가 안 나옴 |
| 연봉 설명이 좁은 열에 갇혀 세로로 길어짐 | 반영 | 비용 칸을 한 줄 전체 폭으로, 세 줄: **연봉 · 이적료** 14억 · 104억 / **첫해 합계** 118억 / **추정 금액 ⓘ**(누르면 연봉 근거 · 이적료 설명, 협상에서 확인되면 「확인 금액」). 「계약 · 합류 1년 · 즉시」 한 줄. 보고서 머리의 등번호(아직 우리 선수가 아님) 뺌 |
| 우리 수비 상황에 「득점권 찬스」 | 반영 | 경기 중 「주요 장면에서 멈춤」 이유가 우리 수비면 **「7회 실점 위기」**. 중계 멘트도 편에 맞게: 우리 공격 「득점권 찬스를 살리지 못합니다 / 만루 찬스에서 병살」, 우리 수비 「실점 위기를 넘깁니다 / 실점 위기를 삼진으로 막아냅니다 / 병살로 위기를 넘깁니다」 |
| 시작은 단장, 부임 안내는 감독 | 반영 | 「○○ **감독**으로 시작」 · 부임 소식 「○○의 감독으로 부임했습니다」 · 협상 자리 「감독 (나)」. (상대 구단 협상 담당자는 그대로 「○○ 단장」) |
| 결과 확인 후 계속 | 반영 | 경기 끝 단추 **「다음날 ▶」** |
| 확정 직전에야 아는 「신규 외국인 계약 상한 14억 초과」 | 반영 | 협상 화면 「보낼 수 없음 · 외국인 계약 상한 초과」 + 확정 전 확인에 [연봉을 상한 14억에 맞추기] (예전엔 보낸 뒤 알림으로만 나옴) |

## 2. 편의 — 영입 진행 통합 · 계약 확정과 교체 연결

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 「교체 대상 고르기」를 누르면 기존 선수 「방출」부터 | 반영 | 정원이 차도 단추는 **「협상 시작 · 첫해 34.8억」**, 아래 한 줄 「외국인 정원 참 (4명) · 협상 뒤 계약 확정 때 교체할 선수를 고릅니다 — 지금 내보내지 않음」. 흐름: 후보 비교 → 구단·선수 협상(협상 화면에 「외국인 정원 참 · 계약 확정 때 교체할 선수를 고릅니다 [미리 고르기]」) → 확정 전 확인 「교체할 외국인 고르기」 → 목록(역할 · 연봉 · **방출 위약금**, 바꿔도 정원이 안 맞으면 「바꿔도 정원 초과」, 단추는 「교체 대상」 — 방출 단추 없음) → **「최종 확인」 계약 · 교체(위약금) · 바로 지출** → 최종 확정. 선수가 거절하면 아무도 안 나감. 위약금은 실제 방출 계산(연봉×남은 해×30%) 그대로 — 예전 창의 「남은 연봉은 그대로 냅니다」는 실제와 달라서 고침 |
| 「진행 중·받은 제안·협상 목록」 경계가 겹침 | 반영 | 이적 위 줄 **진행 중 · 선수 찾기 · 트레이드 · 내 계약 · 신인** (이적 첫 화면 = 진행 중). 진행 중 「전체」 한 목록: **답변 필요**(배치 대기 [배치] → 받은 제안 [제안 검토] → 보고서 도착 [검토] → 구단·선수 협상 [조건 확인]) 위, **기다리는 중**(집중 관찰 n주 남음 · FA 결정 대기) 아래, 완료·끝난 협상은 접힘. 아래 줄 「전체 · 받은 제안 · 협상」은 상세 화면 |
| 트레이드 매물을 「선수 찾기」 안으로 | 부분 | 트레이드는 위 줄 칸으로 따로 둠 — 트레이드 시장·제안 작성 두 화면이 있어 선수 찾기 아래 줄이 6칸이 됨(휴대폰에서 넘침). 위 줄은 5칸 규칙 안 |
