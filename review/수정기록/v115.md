- 국내 경기·선수 기록·밸런스 그대로. 해외 리그 간이 순위는 게임 본 난수와 **따로** 굴려 국내 결과에 영향 없음
- 새 `test/v115_r097.js` · npm test 전체 통과
- 393×852(아이폰 화면 크기)로 선수단 목록(투수·타자) · 순위표 리그 전환을 찍어 확인

| 항목 | 결과 | 확인 방법 |
|---|---|---|
| 1. 내림차순을 종합 옆에 | 반영 | 선수단 → 선수. 필터 줄 = 「전체 ▾」「등급 ▾」 │ 「종합 ▾」「▼」 한 줄. 「▼」를 누르면 「▲」(오름차순). 아이폰 기본 셀렉트 모양이 커서 줄이 넘치던 것을 → 셀렉트 모양을 게임 것으로 통일(작은 화살표), 「정렬」 글자 뺌(노란 칸이 정렬), 「능력치」 필터 이름은 「등급」 |
| 2. 목록만 스크롤 | 반영 | 휴대폰에서 선수 목록이 화면보다 길면 **목록 칸만 스크롤**, 표 머리줄(선수명·포지션·나이·종합·컨디션)은 맨 위에 고정. 위 구단 줄·탭·1군/2군·투수/타자·필터와 아래 [상세][보직][1군 등록]은 움직이지 않음(페이지 자체는 거의 안 움직임). FA·해외·국내 선수 찾기 목록에도 같은 장치를 걸어 둠(목록 아래 다른 칸이 많으면 예전처럼 페이지 스크롤). PC는 그대로 |
| 3. 엉성함 | 부분 | 선수단 목록에서 눈에 띄던 것: 「이름을 누르면 상세, 줄을 누르면 선택…」 설명 줄 삭제(고르면 왼쪽 단추가 「📋 선수 이름」으로 바뀜) · 컨디션 칸의 「→ 100%」 화살표 삭제(오르내릴 때만 ▲▼) · 필터 셀렉트 높이·모양 통일 · 목록이 아래 단추 밑으로 깔리던 것(목록만 스크롤로 해결). 육성·이적 화면은 「어디가 엉성한지」 짚어 주면 같은 방식으로 맞추겠음 |
| 4. 다른 리그 순위 | 반영 | 리그 → 순위표 제목 **「한국 프로야구 ▾」를 누르면 [한국][일본][미국][대만]** → 고르면 그 리그 순위표(일본 센트럴·퍼시픽, 미국 지구·와일드카드, 대만 전·후반기). 원래 우리가 뛰지 않는 해외 리그는 경기를 아예 안 돌려 0승 0패였음 → **간이 순위**: 날마다 전력(주마다 다시 잰 팀 전력)으로 승패·점수만 정해 쌓음(선수 기록은 안 쌓임, 화면에 「간이 순위 · 승패·득실만」). 시즌 끝엔 리그별 정규 경기 수에 맞음, 새 시즌에 0부터. 우리 구단이 해외 리그에 있으면 그 리그는 예전처럼 실제 경기 |
