## 7시즌 점검에서 찾은 것

| 찾은 문제 | 결과 | 확인 |
|---|---|---|
| **「선택 n명 코치에게 위임하고 진행」을 눌러도 0명 재계약** — 체크는 보이는데 내부 선택이 비어 있어 핵심 선수가 전부 FA로 떠남(2시즌 겨울 36명 → 14명) | 반영 (버그) | 겨울 → 개막까지 → 「개막 전 확인」 → 위임 → 토스트 「코치 위임: n명 재계약」, 만료 명단이 n명 줄어듦 |
| **겨울을 건너뛰면 자동 지명한 신인이 한 명도 안 들어옴** — 「남은 우리 차례는 자동 지명」이라 해 놓고 지명 직후 대학 진학 처리 | 반영 (버그) | 1주차에 개막까지 → 안내 「신인 지명 남은 우리 차례 n번은 자동 지명 · 입단 계약」 → 개막 뒤 선수단에 그해 지명 신인(계약금은 지명 때 요구액) |
| 위임 기본 선택이 핵심 선수만이라 해마다 인원이 줄어 **개막 불가**(5시즌 연속) | 반영 | 기본 체크 = 핵심 선수 + 개막 최소 인원(선수 20 · 투수 9 · 야수 10 · 포수 1)을 채울 만큼 가치순. 창에 **「개막 인원 28명 (최소 20)」** 한 줄 |
| 인원이 모자라 개막이 안 되면 토스트 한 줄만 뜨고 멈춘 것처럼 보임 | 반영 | 「개막 불가 · 선수단 요건 미달」 창: 이유(예: 투수 8명 (최소 9명)) + [FA 시장에서 채우기] [최소 인원 자동 보충 후 개막] |
| 「개막 전 확인」 맨 아래 「돌아가기」 = 위 「닫기」와 같은 단추 | 반영 | 단추 셋: 재계약 명단 정리 · 위임하고 진행 · 그대로 진행 |
| 겨울 개막 확인 창에 바뀌지 않은 선발진·단위가 그대로 나열 · 「돌아가기」 중복 | 반영 | 「선발진 그대로 · …」, 바뀐 단위만(없으면 「변화 없음」), 단추는 [개막] 하나 |
| 결산 「내년」이 준PO에서 떨어진 5위에게도 「우승 도전」 | 반영 | 가을야구 실패 → 가을야구 재도전 · WC/준PO/PO 탈락 → 상위권 도전 · 준우승 → 우승 재도전 · 우승 → 2연패 도전 |
| 겨울 선수 목록 마지막 칸(지난 시즌)이 길어서 잘림 | 반영 | 겨울 → 선수단 → 선수. 투수 「3.97 · 3승」, 타자 「.287 · 12홈런」, 1군 기록이 거의 없으면 「2군 .300」 |
| 트레이드 시장 「구단별 수요」 표가 폰에서 화면 밖으로 넘침 | 반영 | 이적 → 트레이드 시장. 보강 포지션 칸이 줄바꿈, 가로 스크롤 없음 |
| 홈 「▶▶ 자동 진행」이 하루만 진행하는데 옆 「7경기 자동」과 헷갈림 | 반영 | 오늘 경기 카드 단추 「이 경기 자동 · 7경기 자동 · 시즌 끝까지」 |
