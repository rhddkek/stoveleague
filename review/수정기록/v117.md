## 고친 것

| 찾은 문제 (화면에서 본 그대로) | 결과 | GPT가 확인할 방법 |
|---|---|---|
| **아래 「육성」을 눌렀는데 이적 화면이 열림** — 이적 → 신인 → 국내 스카우트(또는 유소년)를 한 번 보고 나면 그 뒤로 계속 | 반영 (버그) | 이적 → 신인 → 국내 스카우트 → 아래 「육성」 → 훈련·성장 화면 |
| **영입·성장한 선수가 계속 벤치** — 타순을 직접 안 고치면 개막 때 2루수 56이 주전이고 벤치에 62·74가 앉아 있음, 선발 71이 불펜에 있고 51이 선발, 가장 좋은 불펜(75)이 선발 자리에 들어감. 대구가 선수 능력은 리그 1~2위인데 36승 108패를 반복한 원인 | 반영 | 겨울 → 개막까지 → 「개막 전 점검」 창에 **「편성 점검 · 주전보다 나은 선수 n명 · 중견수 ○○ 70 > △△ 61」 + [자동 편성]**. 누르면 「자동 편성 완료 · 타순·선발 로테이션·불펜」. 나은 선수가 없으면 줄이 안 나옴. 빈 선발 자리는 불펜에 있는 선발 투수 중 가장 좋은 선수부터 채움 |
| **「7경기 자동」이 거의 매일 멈춤** — 「볼 만한 경기 — ○○ 1군 데뷔 가능」에서 [계속 자동]을 눌러도 그 선수가 실제로 나올 때까지 다음 날 또 멈춤(7시즌에 272번) | 반영 | 시즌 중 7경기 자동 → 볼 만한 경기에서 멈춤 → [계속 자동] → 같은 이유로는 다시 안 멈춤 (고친 뒤 7시즌 4번) |
| **위임이 같은 창만 되풀이** — FA를 먼저 사서 연봉 한도가 모자라면 「코치에게 위임」을 눌러도 토스트만 뜨고 같은 창이 같은 체크로 다시 뜸 | 반영 | 「개막 전 확인」에서 위임 → 예산이 모자라면 **「연봉 예산 부족 · n명 재계약 불가 (추가 연봉 한도 ○○)」 + [연봉 한도 늘리기]**, 못 한 선수 줄에 「예산 부족」, 체크는 풀리고 위임 단추는 꺼짐. [그대로 진행]은 그대로 |
| 겨울에 계약한 선수의 계약 기간이 「2026~2027」(이미 끝난 시즌부터) | 반영 | 겨울 → 선수 상세 → 프로필 「계약 기간」 = 다음 시즌부터 (2년이면 「2027~2028」). 만료된 선수는 「만료」 |
| 영입 완료 카드: 선수 상세는 「우투양타」인데 카드는 「우투우타」 · 「계약 완료」가 두 번 | 반영 | FA 계약 확정 → 영입 완료 카드 타석 표기가 선수 상세와 같고 「계약 완료」 한 번 |
| FA 협상 머리글: 유격수인데 「지명타자 주전 ○○ 66 → 66 · 보강 효과 없음」 | 반영 | 어디에도 보강이 안 되면 제 포지션과 비교 — 「유격수 주전 ○○ 71 · 백업 (66)」 |
| FA 「✓ ① 개인 요구 충족」인데 내 제안이 요구보다 낮음(−6,100만) | 반영 | 괄호에 「… · 총액 93%부터 수락」 |
| 겨울을 건너뛰면 계약 끝난 코치가 말없이 떠남(3시즌에 코치 0명) | 반영 | 개막까지 → 「자동으로 처리되는 것」에 **「재계약 안 한 코치 n명은 떠남」** |
| 코치 창: 칸은 「잔여 1년」인데 창은 「1년 남음」 · 닫기 두 개 · 67세 이상은 [2년 재계약]을 눌러도 「은퇴를 결심」 토스트만 | 반영 | 코치 칸 → 창 「잔여 1년」, 닫기 하나. 67세 이상 만료 코치는 꺼진 단추 「은퇴 결심 · 재계약 불가」 |
| **탭 이름과 바로 아래 제목이 같은 화면 11곳** (화면 규칙 위반) | 반영 | 스쿼드 플래너 → 「자리별 3년 전망」 · 명예의 전당 → 「헌액 선수」 · 라커룸 → 「팀 분위기」 · 훈련 → 「이번 주 훈련」 · 장비 → 「장비 관리」 · 영입 요청 → 「영입 공고」 · 트레이드 시장 → 「시장 현황」 · 국내 스카우트 → 「스카우트 파견」 · 올스타전(열리기 전) → 「개최 예정」 · 감독 채용 → 「채용 공고」 · 옛 제자 → 「지도했던 선수」. 검사가 시즌·겨울 모든 화면을 돌며 대조 |
| 밝은 테마 육성 → 성장의 「종합」 숫자가 노란 글자라 안 보임 (대비 1.25) | 반영 | 설정 → 밝은 테마 → 육성 → 성장 → 선수 고르면 종합 숫자가 진한 글자. (육성 탭이 이적으로 열리던 탓에 그동안 검사에서 빠져 있던 화면) |

## 광우 판단이 필요한 것 (보류 — 수치는 안 건드림)

| 관찰 | 화면·기록에서 본 숫자 | 원인으로 보이는 것 |
|---|---|---|
| **리그가 해마다 어려지고 약해짐** | 국내 1군 선수 중 종합 60 이상 195명 → 7시즌 뒤 150명 안팎. 23세 이하 146명 → 207명, 32세 이상 44명 → 20명, 24~27세 101명 → 56명. 평균 나이 25.7 → 23.5 | 해마다 종합 60 이상 12~26명이 FA로 나와 개막 때까지 무소속(예: 24세 종합 88, 23세 82, 27세 81), 2년 무소속이면 게임에서 삭제(해마다 60 이상 7~15명). AI 구단은 **빈 포지션만** FA로 채우고, 샐러리캡에도 걸림 |
| **국내 대형 FA에 경쟁이 없음** | 종합 79 이상 국내 FA는 거의 「경쟁 0」(조성민 81 · 연봉 68.4억, 김지원 80 · 47.7억, 방성준 82 · 78.2억). 외국인(연봉 14억 상한)에는 2~3구단이 붙음 | FA 요구액 = 평소 연봉의 최대 2.6배 + 계약금 35%. AI 구단은 「현금 ≥ 총액 × 1.4」일 때만 제시하는데 AI 현금은 270~510억 → 총액 300억대부터는 아무도 못 냄 |
| **기록이 비현실적으로 커짐** | 홈런 1위 39 → 52 → 56 → 63 → 65개, 타율 1위 .360 → .387 → .401 → .451, 평균자책 1위 1.33~1.46, OPS 1.000 이상 10명 | 리그 투수층은 얇아지는데 종합 85~88 타자는 남아 있음 (위 항목의 결과) |
| **현금은 쌓이는데 쓸 수가 없음** | 대구 현금 700억 → 1,100~1,600억. 그런데 추가 연봉 한도는 0~20억, 영입 예산 150~170억은 FA에 못 씀 | 연봉 한도가 현금이 아니라 리그 평균 연봉 기준. 「예산 조정」은 15억 → 5억, 3회뿐 |
| **감독이 잘리지 않음** | 대구 5년 연속 10위(26승 118패, 14승 130패)에도 그대로. 평판 8~12 | 유저 감독 해임 규칙이 없음 |
| 선발진이 약하면 한 시즌이 통째로 무너짐 | 선발 50대 5명이면 야수 종합이 리그 1위여도 100패 | 경기 계산상 선발 비중이 큼 — 의도인지 확인 필요 |
