## 선수단 명단 (시안 1)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 「선택 n명 │ 선수 관리」 | 반영 | 선수단 → 명단. 맨 아래에 **「선택 0명 │ 선수 관리」**(꺼짐). 줄을 누르면 「선택 **1**명」 + 노란 **[선수 관리]** → 누르면 관리 창: 선수 정보 · 라인업/보직 · 1군 말소 → 2군(2군이면 1군 등록) · 육성군으로 · 임대 보내기 · 매물 등록 · 재계약 협상 |
| 육성군 칸 | 반영 | 위 칸이 **1군 n/n │ 2군 │ 육성군** (임대 보낸 선수가 있으면 넷째 칸 「임대」). 2군 칸에는 선수단에 든 2군 선수만, 육성군 칸에는 육성군만. 육성군 선수를 누르면 카드 단추 **[상세] [2군 등록]** |
| 제목 + 찾기 | 반영 | 탭 위에 큰 제목 **「선수단」**과 오른쪽 돋보기(선수 · 화면 · 용어 찾기) |
| 칩 · 표 | 반영 | 칩은 숫자 없이 **전체 · 타자 · 투수 · 부상**. 포지션 칸은 단추가 아니라 글자(LF · SS · CP). 종합과 상태 사이 세로줄. 보직·포지션 바꾸기는 [선수 관리]에서 |
| 고른 선수 카드 | 반영 | 큰 얼굴 · **「황선우 · C · 24세」** / 「1군 벤치 · 종합 64」 · [상세] [2군 이동]. 아무도 안 골랐으면 카드 없음 |

## 겨울 감독실 (시안 2)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 머리줄 주차 칸 | 반영 | 겨울 감독실 머리줄 오른쪽에 노란 테두리 **「겨울 1주차」**. 화면 안 「겨울 n주차 · 마감 …」 줄은 없앰 (놓치면 손해 보는 것이 있을 때만 그림 아래 빨간 테두리 한 줄) |
| 큰 그림 · 돈 세 칸 | 반영 | 그림 92px, 화면 양끝까지. 그 아래 **(동전) 현금 · (악수) 영입 · (명세서) 연봉 여유** — 상자 없이 세로줄만 |
| 오늘 할 일 | 반영 | 제목 「▌오늘 할 일 n」 아래 **줄마다 따로 둥근 카드**: 아이콘 │ 제목 │ 설명 │ 노란 단추, 한 줄. 답변 기다리는 협상이 있으면 맨 끝에 「답변 대기 │ n건 │ [보기]」 |
| 전력 보강 | 반영 | 제목 「▌전력 보강」(오른쪽 「진단 ›」) 아래 **선수 그림이 든 카드 두 장**: 「선발진 / 리그 8위 / [투수 찾기]」. 영입했으면 「✅ ○○ 영입」, 답을 기다리면 「⏳ ○○ 대기」 |
| 이번 주 성장 | 반영 | 「**이번 주 성장** │ 얼굴 이름 │ 62 → **67** │ +5 │ ⌄」 → 누르면 육성 → 성장. 「다음 주로」를 눌러 넘어온 주에 실제로 종합이 오른 선수가 있으면 「이번 주 성장」, 없으면 「시즌 성장」(지난 개막 → 지금)으로 이름을 바꿔 보여 줌. 숫자 = 그 선수의 지금 종합 |
| 뉴스 | 반영 | 「(신문) 뉴스 │ 가장 최근 소식」 몇 초마다 바뀜 → 누르면 소식 모음. 이 화면에서는 아래 메뉴 위 소식 띠를 숨김(같은 내용 두 번 안 나오게) |
| 큰 「다음 주로」 | 반영 | 화면 폭 전체 노란 단추 **「다음 주로 ▶ / 미처리 n건 · 1 → 2주차」**, 늘 아래 메뉴 위에 붙어 있음. 그 밑 작은 글자 「개막까지 건너뛰기 ▶▶」 |
| 지난 시즌 결산 · 영입 완료 | 반영 | 뉴스 줄 아래 접힌 한 줄 「지난 시즌 결산 · 영입 완료 n ⌄」. 구단 우편함 카드는 없앰(뉴스 줄 · ☰ 메뉴로) |

## 타순·수비 (시안 4)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 제목 + 초기화 | 반영 | 선수단 → 타순. 「타순·수비」 오른쪽 노란 글자 **초기화** → 이 화면에 들어왔을 때(또는 마지막 저장) 타순으로 되돌림. 바꾼 게 없으면 「바꾼 것이 없습니다」 |
| 운영 방침 | 부분 | 시안의 「기본 │ 좌투 상대 │ 우투 상대」 자리에 **승리 │ 공격 │ 유망 │ 체력**, 그 아래 칸 「승리 우선 · 수비력 68 · 적성 밖 2」. 좌·우 상대 라인업은 보류(아래) |
| 왼쪽 타순 │ 오른쪽 수비 그림 | 반영 | 왼쪽 9줄(☰ · 번호 · 얼굴 · 이름 · 포지션 칩), 오른쪽 구장 그림에 **등번호 유니폼 + 포지션**. 고른 선수는 양쪽 모두 노란 표시. ☰를 끌거나 눌러 타순 바꾸기, 구장 자리를 누르면 그 자리 선수 고르기(그대로) |
| 적성 밖 경고 | 반영 | 제 포지션이 아닌 자리가 있으면 방침 칸 아래 주황 줄 「⚠ ○○ 포수 적응 부족 -12」 |
| 교체 후보 | 반영 | 줄을 누르면 「교체 후보 · 8번 2B ○○」 아래 카드 세 장(얼굴 · 이름 · 종합). 카드를 누르면 노란 테두리 |
| 비교 한 줄 | 반영 | 「김승우 51 → 황선우 64 │ +13」(그 자리에서의 능력). 적성 밖이면 오른쪽에 「⚠ 2루수 수비 부적합」 |
| [자동 편성] [라인업 저장] | 반영 | 아래 고정 두 단추. 후보 카드를 고른 뒤 **라인업 저장** → 그 자리에 들어가고 저장 |

## 투수진 (시안 3)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 제목 + 그림 · 선발 │ 불펜 | 반영 | 선수단 → 투수진. 「투수진」 오른쪽 투수 그림. 그 아래 **선발 │ 불펜** (예전 투수단 · 상태 · 계약 세 칸은 없앰 — 상태는 명단, 계약은 선수 상세에) |
| 최근 5경기 한 줄 | 반영 | 「최근 5경기 ERA 3.50 · 3승 1패」 = 우리 투수들의 경기별 기록에서 최근 5경기 합. 경기 전(겨울 포함)에는 「선발 ERA · 불펜 ERA」 |
| 선발 다섯 줄 | 반영 | 줄마다 「1선발 │ 얼굴 이름 │ 종합 74 │ 체력 막대 100% │ 휴식 4일」. 다음 경기 선발은 **노란 테두리 + 「다음 선발」**. 휴식 = 마지막 등판 뒤 지난 날, 아직 안 던졌으면 「등판 전」 |
| 등판 순서 | 반영 | 동그란 얼굴 다섯 ▸ ▸ ▸ (다음 선발부터) 「4일 / 1선발」 |
| 교체 후보 표 · 비교 줄 | 반영 | 「▌교체 후보」 표(선수 │ 종합 │ 체력) 세 줄, 2군 선수는 이름 옆 「2군」. 줄을 누르면 고름. 아래 「박용호 46 → 임종현 58 │ +12」. 선발 줄을 누르면 그 선발이 바꿀 대상(안 고르면 가장 약한 선발) |
| [자동 편성] [선발 교체] | 반영 | 자동 편성 = 선발 로테이션·불펜만(타순은 안 건드림). 선발 교체 = 비교 줄대로 바꿈. 2군 투수인데 1군이 꽉 차 있으면 안내 |
| 불펜 | 반영 | 불펜 칸: 「마무리 1 · 필승조 2 · 추격조 4 · 불펜 ERA」 + 줄마다 보직 고르기 │ 얼굴 이름(최근 등판) │ 종합 │ 체력 |

| 구단 → 감독 → 감독 채용 | 반영 | 위 알약 「지원 기간 · 스토브리그 1~2주」(겨울 1~2주차엔 「지금 지원 가능 · 스토브리그 2주차까지」). 줄: 엠블럼 │ 구단 / 나라 │ 사유 · 요구평판(모자라면 빨강, 되면 초록) › — 누르면 노란 테두리. 아래 카드: 엠블럼 │ 구단 · 「지원 시기 비시즌」 · 「평판 25 / 58 │ 부족 33」 · [내 실적] [지원 불가](꺼짐). 지원 기간이고 자격이 되면 노란 [지원], 제의가 와 있으면 [제의 보기] |
| 육성 → 장비 → 상점 | 반영 | 위 밑줄 탭 **장착 │ 상점**. 타자 │ 투수 → 아이콘 6칸 → 큰 칸 「‹ 장비 그림 › / 파워 배트 / [파워 +2](초록) [컨택 −1](빨강)」 → 표 **가격 · 보유현금 · 구매후**(초록, 모자라면 빨강) → 보유 수량 → 칩 [시즌종료시 소멸](빨강) [선수당 3칸] [동일장비 1개] [능력별 ±3한도] → 이용안내 ⌄ → 아래 고정 노란 **구매 · 12.5억** (누르면 예전처럼 확인 창) |
