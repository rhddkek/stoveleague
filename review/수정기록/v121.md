## 좌투·우투 상대 타순 (R102 보류 → R104 「없는 기능은 넣어」)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 좌·우 상성 (경기 계산) | 반영 | 반대 손 투수를 만난 타자는 컨택·파워 **+1.2**, 같은 손은 **−1.8**, 스위치 타자는 늘 반대 손 취급. 타자 구성(우 40·좌 40·양 20%)과 투수 구성(우 75·좌 25%)에서 반대 손 타석이 60%라 0.6×1.2 = 0.4×1.8 — 리그 평균은 그대로 |
| 전후 수치 (36경기 한 시즌, AI만) | — | 시드 2026: 경기당 득점 4.45 → **4.46**, 리그 타율 .261 → **.261** · 시드 777: 4.47 → **4.40**, .259 → **.259** |
| 기본 │ 좌투 상대 │ 우투 상대 | 반영 | 선수단 → 타순. 위 칸 셋. 좌투 상대 칸을 처음 열면 「좌완 선발 상대 타순을 아직 따로 안 짰습니다 — 지금은 기본 타순으로 나갑니다」. 그 칸에서 타순·수비를 바꾸면(끌기 · ☰ · 구장 자리 · 교체 후보 · 자동 편성 모두) **그 칸 타순만** 바뀌고 기본은 그대로. 짜 둔 칸에는 초록 점 |
| 경기에 적용 | 반영 | 상대 선발이 좌완인 날은 좌투 상대 타순, 우완인 날은 우투 상대 타순, 안 짰으면 기본. 그 타순에 부상·2군 선수가 끼어 있으면 그날은 기본 타순 + 칸에 주황 경고 「⚠ … 지금은 기본 타순으로 나갑니다」 |
| 타자 손 표시 | 반영 | 좌투/우투 상대 칸에서는 이름 옆 **좌 · 우 · 양**(유리하면 초록, 불리하면 빨강) |
| 초기화 | 반영 | 좌투/우투 상대 칸에서 「초기화」 = 그 타순을 지우고 기본으로 |
| 운영 방침 | 반영 | 칸 아래 「승리 우선 · 수비력 68 │ 적성 밖 2 ✎」 → 누르면 승리 · 공격 · 유망주 · 체력 고르는 창 (v120의 네 칸 줄은 없앰) |
| AI 구단 | 그대로 | AI는 타순을 나눠 짜지 않음(기준값). 상성은 양쪽에 똑같이 적용 |
