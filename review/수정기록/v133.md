# v133 수정기록 — 광우 폰 확인: 타순 능력 · 성장 기록 빈칸 · 「0주 남음」 · 방출

- 세이브 형식 그대로(VERSION 6). 경기·성장·AI 계산은 그대로 — 화면만 바뀜
- 새 `test/v133_ui.js` (폰 390·360px 두 폭에서 검사)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 타순 줄에 능력치 | 반영 | 선수단 → 타순. 이름을 14px로 조금 줄이고 그 아래 줄에 **등급+그 자리 능력 · 타n · 수n**(예: 「A 70 타74 수55」). 자리 능력 = 아래 교체 후보 비교와 같은 값, 수비는 적성 밖 자리면 깎인 값(주황), 지명타자는 타격만. 왼쪽 타순 칸을 넓혀(오른쪽 수비 그림은 그대로) 포지션 칸 끝에 찍히던 「.」도 없앰 |
| 성장 기록 왼쪽 빈칸 | 반영 | 육성 → 성장 → 성장 기록. 왼쪽 목록이 이름 · 포지션 · 숫자를 세로로 쌓아 오른쪽이 비던 것 → **얼굴 │ 이름 / 포지션·나이 │ 등급+종합 / 변화** 한 줄 카드(높이 56px, 한 화면에 두 배 가까이) |
| 「0주 남음」 | 반영 | 남은 기간 0 = 그 주가 마지막이라는 뜻(다음 주로 넘기면 사라짐). 감독실 주요 업무 · 협상 목록 · 영입 제안서에서 **「이번 주 마감」**(시즌 중은 「오늘 마감」)으로 |
| 방출 | 반영 | 방출 기능은 있었지만 옛 선수 상세의 「관리」 칸에만 있어 지금 화면에선 안 보였음. 선수단 → 선수를 고르고 「선택 1명 │ 선수 관리」 → 메뉴에 빨간 **방출 — 위약금 n · 연봉 n 절감 · FA로 풀림** → 확인 창(위약금 · 남은 연봉 · 현금 n → n · 선수단 n명 → n명 · 「되돌릴 수 없습니다」) → [방출 확정]. 위약금 = 남은 계약 총액의 30%(기존 규칙 그대로). 선수단 최소 20명이면 확정 단추가 꺼짐 |
