# v135 수정기록 — 코치진에게 맡기기 · 코치 추천 · 마감 일은 처리해야 진행 (광우: 「3번 넣고, 할 일 안 하면 진행 안 되고 그 화면으로」)

- 세이브 형식 그대로(VERSION 6). 새 값 `S.auto`(맡기기 6가지) · `S.mustAck`(이번엔 넘기기) · 코치 `letGo` — 없으면 없는 대로
- 경기·성장 계산은 그대로. AI 구단도 그대로(맡기기는 우리 팀만)
- 막힘은 화면에서 만든 새 게임과 「이어 하기」로 연 저장에만 — 검사용으로 코드에서 바로 만든 게임은 예전처럼 진행(옛 검사 70개 보호)
- 새 `test/v135_auto.js` (6개 항목)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 맡기기 6가지 | 반영 | 감독실 「코치 추천」 카드 오른쪽 위 [맡기기 n/6 ›] → 창 「코치진에게 맡기기」: 드래프트 지명 · 신인 계약 · 코치 재계약 · 겨울리그 파견 · FA 보상 · 2차 드래프트 켬/끔 + [모두 직접][모두 맡기기]. 규칙: 드래프트 = 관심 명단·부족 포지션·잠재 순 / 신인 = 추천 훈련으로 계약 / 코치 = 평가 60 이상 2년 재계약, 아래는 보냄 / 파견 = 25세 이하 비주전만, 나머지 거절 / FA 보상 = 자동 추천 보호 명단·가치 큰 쪽 / 2차 드래프트 = 자동 보호·지명 안 함. 켠 일은 다음 주를 누를 때 처리되고 알림 「코치진 처리: …」 |
| 마감 일은 처리해야 진행 | 반영 | 맡기지 않은 일이 **이번 주 마감**이면 「다음 주」·「개막까지」를 눌러도 넘어가지 않고 **그 화면으로 이동** + 맨 위 노란 테두리 띠 「진행 전에 할 일 — ○○ — 넘기면 …」 [다음 일][이번엔 넘기기][코치진에 맡기기]. 다 처리하면 띠가 「✓ 처리 끝 [다음 주 ▶]」. 막는 일: 드래프트 우리 차례 · FA 보상(그 주 마감) · 2차 드래프트(보호 명단·우리 차례) · 2주차의 코치 재계약 · 2주차의 겨울리그 파견 요청 · 개막 전 신인 계약. 이적 제안 · 광고 제안은 안 막음(안 받으면 거절로 끝나는 일) |
| 이번엔 넘기기 | 반영 | 띠의 [이번엔 넘기기] = 그 주만 넘김. 코치 → 떠남 / 파견 → 모두 거절 / FA 보상·2차 드래프트 → 코치진 판단 / 드래프트 → 예전처럼 자동 지명 / 신인 → 계약 안 한 선수는 대학 진학 |
| 코치 추천 | 반영 | 감독실(시즌·겨울 모두) 위쪽 「코치 추천」 카드, 3개까지. ① 「타순 정리 — 부상 n · 적성 밖 n」 [자동 편성] — 자동 편성하면 실제로 줄어들 때만 뜸(미리 계산한 n→n 표시) ② 시즌 중 「2군 ○○이 1군 △△보다 낫습니다」 [교체] — 종합 4 이상 차이, 주전·선발·마무리 제외 ③ 「○○ 리그 n위 — 약점」 [전력 진단] — 리그 꼴찌·끝에서 두 번째 부문 ④ 겨울에 직접 하는 일이 남았으면 [맡기기] |
| 2번(특수 능력) | 해당 없음 | 이미 「특성」 9가지(성실 · 클러치 · 장타본능 · 강철체력 …)가 경기·성장 계산에 들어 있음 — 이번 판은 손대지 않음 |

## 기본값
- 화면에서 만든 새 게임: 신인 계약만 맡김(나머지 직접 → 마감 주에 막히면 띠에서 바로 맡길 수 있음)
- 이어 하기로 연 예전 저장: 모두 직접(같은 방식)
