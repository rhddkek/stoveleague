| 1-④ RP·SP 추천 | 반영 | 「2군 ○○이 1군 △△보다 낫습니다」 · 「부상 ○○ — 2군 △△ 올리기」는 같은 보직(SP↔SP, RP↔RP)을 먼저 찾음. 다른 보직은 종합 차이가 7 이상일 때만 나오고 줄 끝에 영향 표시: 「선발 투수를 불펜으로 씀 (긴 이닝 강점은 못 살림)」 / 「불펜 투수가 선발 — 체력 48, 긴 이닝 어려움」 |
| 1-⑤ 재계약 금액 표시 | 반영 | 재계약 표 아래 줄 「연봉 +64억」 → **「새 연봉 합계 64억 · 기존 대비 +31.3억」**. 결정 실행 알림 · 개막 전 확인 창 · 예산 초과 확인 창도 같은 말 |

| 1-⑦ 외국인 4/4 | 반영 | 다 채우면 경고 대신 **「구성 완료 4/4」**(외국인 관리 · 해외 선수 찾기 머리줄 · 외국인 관리 단추). 「쿼터 모두 사용 중」 경고 상자는 없앰 |
| 1-⑧ 광고 여러 건 | 반영 | 광고 창 제목 「개인 광고 제안 2건 중 1」 · 단추 [수락 · 다음 제안][거절 · 다음 제안] → 다음 건이 바로 뜸 → 마지막 건을 처리하면 창이 닫히고 감독실 |
| 1-⑨ 겨울 파견 | 반영 | 할 일 목록(또는 「겨울리그 파견 요청 n건」 창)의 줄마다 **[국내 잔류][파견]** — 상세에 들어가지 않고 바로 처리, 남은 요청이 있으면 목록이 다시 뜸 |
| 2 외국인 교체 흐름 | 반영 | 이적 → 해외 → 「외국인 관리」(또는 외국인 선수 메뉴 「외국인 교체」, 외국인 방출 직후 자동). 첫 화면 = **자리 표**: 일반 1 · 일반 2 · 일반 3 · 아시아 / 현재 선수(보직 · 연봉) / [교체](겨울 계약 만료면 [유지 n억][교체]) · 빈자리는 [후보 찾기]. 교체·후보 찾기 → 그 자리 후보만(투수/타자 · 예산 안 · 아시아 자리면 아시아 가능만) → [협상] → 계약 → 배치 → **배치하면 다음 빈자리 후보 화면이 바로 열림**(없으면 외국인 관리 「구성 완료 4/4」). 교체를 골랐으면 그 선수는 계약 확정 때 내보냄(먼저 방출하지 않음) |
| 3 후보 줄 연봉·쿼터 | 반영 | 후보 줄 두 줄: 「다카하시 히로시 RP 58~66」 / 「아시아 가능 · 연봉 1.5억 · 이적료 1.8억」(FA면 「FA · 이적료 없음」) / 작은 글씨 국적 · 나이 · 소속. 연봉은 그 자리 조건으로 미리 계산(아시아 자리 = 아시아쿼터 연봉, 상한 2.8억 넘는 선수는 안 나옴). 방금 내보낸 선수는 후보에서 빠짐 |
| 4 협상 지금 답 | 반영 | 이적료가 모자라 거절되면 맨 위(금액 칸 위)에 고정: 「거절 · 이적 합의금 부족 · 제안 n회 남음」 / 상대 말 / **「내 제안 17.7억 → 요구 20.8억 (3.1억 부족)」** / [요구대로 20.8억][수정][중단]. 지난 대화만 「협상 기록」에 접힘. 아래 별도 「요구대로」 단추는 이때 숨김 |
| 4 조건 열람 / 제안 구분 | 반영 | 아직 한 번도 제안하지 않았으면 아래 단추가 「닫기 (조건만 보기)」 — 누르거나 ‹ 뒤로 가면 **협상 기회를 쓰지 않고** 그냥 나감(「협상 중단 · 재협상 가능 1회」 화면 안 나옴, 알림 「조건만 확인했습니다 — 협상 기회는 그대로」). 한 번이라도 제안했으면 예전처럼 「취소 (협상 중단)」 |
| 5 모바일 중복 축소 | 반영 | 외국인 화면 위는 한 줄 「일반 2/3 · 아시아 0/1 · 연봉 여유 5.3억」(+「빈자리 n」/「구성 완료」 꼬리표), 해외 선수 찾기 머리줄도 같은 한 줄(휴대폰 돈 세 칸 줄 없앰). 후보 화면 아래 고정 한 줄 「이름 · 첫해 n억 · ○○ 대신 [협상]」. 능력 상세는 이름을 한 번 더 누르면 스카우트 보고서 |
| 6 연패 원인 + 행동 | 반영 | 3연패 이상이면 감독실 「코치 추천」 첫 줄 + 순위 → 「최근 5경기」 카드에: 「6연패 — 최근 5경기 선발 ERA 8.00 / 시즌 선발 ERA 4.12 — 선발이 일찍 무너지는 중 [선발 점검]」. 원인은 실제 기록에서 하나만(선발 ERA · 불펜 ERA · 경기당 득점 중 시즌보다 가장 크게 나빠진 것, 기준을 못 넘으면 안 나옴) → [선발 점검]/[불펜 점검] = 투수진 해당 칸, [타순 점검] = 타순 |
