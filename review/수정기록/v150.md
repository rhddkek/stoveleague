# v150 수정기록 — R121 (진행이 걸리던 여섯 곳)

- 원문: `review/요청/R121_진행_매끄럽게.md`. 세이브 · 경기 계산 변화 없음. 새 `test/v150_r121.js`(7묶음). 휴대폰 폭 기준.

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 알림이 탭을 가림 | 반영 | 새 게임 → 선수단 → 타순. 「첫 시즌 할 일 1/6 — ✓ 라인업 보기」 알림이 맨 위 머리줄 왼쪽(구단 이름 자리)에 뜨고, 위 탭 줄과 오른쪽 「메뉴」 · 「경기」 단추는 그대로 보임 |
| 드래프트 끝 | 반영 | 겨울 1주차 → 하나씩 처리 → 지명. 마지막 지명의 「입단 확정」 창 단추가 「지명판」 대신 **「다음 할 일 ▶」** → 감독실로 돌아가며 「할 일 2 / 3」 창이 바로 이어짐(남은 일이 없으면 「감독실로 ▶」). 지명 도중에는 그대로 「다음 지명」 |
| 알약 | 반영 | 「할 일 n건 남음 · 다음 ▶」 알약이 화면 오른쪽 아래 작은 단추로(가운데 큰 알약 → 오른쪽 36px). 목록 줄을 타고 올라가 한가운데를 덮지 않음 |
| 겨울 숫자 | 반영 | 겨울 감독실: 「주요 업무 3」 = 「다음 주 · 미처리 3」 = 「할 일 1 / 3」(선택 업무는 세지 않음). 할 일이 남은 동안 「다음 주」는 테두리만, 노란 단추는 「하나씩 처리 ▶」 하나. 다 하면 「다음 주」가 노란 단추 |
| 영입 조작 줄 | 반영 | 이적 → 영입 → 국내 선수: 「🔍 검색·필터」와 「한도 안 · 영입 가능(의향) · 부족 포지션」이 한 줄(넘치면 옆으로 밀기). 표 위 예산 칸(현금 · 예산)은 휴대폰에서 빼고(머리줄에 같은 값) 「한도 안」 기준 설명만 작은 한 줄로 남김. PC는 그대로 |
| 감독실 진행 단추 | 반영 | 시즌 중 감독실: 「▶ 경기 보기」 아래 **[7경기 자동] [⋯]** 둘뿐. ⋯ → 이 경기 자동 / 7경기 자동 / 시즌 끝까지 — 고른 방식이 왼쪽 단추에 남음. 가을야구는 「이 경기 자동」 하나 |
| 전반기 결산 재등장 | 반영 | 올스타 브레이크의 「전반기 결산」 창을 「닫기」 · 바깥 누르기로 나가도 본 것으로 처리 → 뒤 진행에서 다시 안 뜸. 다시 보려면 리그 → 순위 → 「전반기 결산 다시 보기 ›」(새로 넣음 · 이때 창 단추는 「닫기」) |
