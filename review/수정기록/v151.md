# v151 수정기록 — R122 (AI 티 나는 곳 다듬기)

- 원문: `review/요청/R122_AI티_다듬기.md`. 세이브 · 경기 계산 · 화면 구성 변화 없음(색 · 글자 크기만).
- 점검: 휴대폰 폭 · 어두운 색에서 제목 → 새 게임 → 감독실 → 여섯 영역의 모든 위/아래 탭 + 선수 카드 · 관리 메뉴 · 선수 상세 · 메뉴(60여 화면)를 자동으로 훑어 unslop 점검표의 신호를 셈.
- 결과: 이모지 아이콘 0 · 느낌표 0 · 기울임 0 · 대문자 넓은 자간 0 · 색 그라디언트 0(그림 위 어둡게 덮는 것 3곳뿐) · 색 번짐 0 · 되풀이 움직임 0 · `transition:all` 0 — 큰 틀은 이미 정리돼 있어 「가볍게 다듬기」로 진행. 남은 신호만 고침.

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 강조색이 둘(노랑 + 초록) | 반영 | 제목 화면 「○○ 감독으로 시작」, 이적 → 영입 → 스카우트의 큰 단추가 초록(흰 글자, 대비 2.3) → 노란 바탕 + 검은 글자. 제목 화면에서 고른 탭 · 구단 칸 · 구단 설명 테두리도 초록 → 노랑 |
| 밝은 배지 위 흰 글자 | 반영 | 등급 배지 A·B·C·D(주황 · 초록 · 파랑 · 회색), 최근 5경기 승/패 칸의 글자를 검은색으로(대비 2.3~3.7 → 4.5 이상). 자동 점검에서 대비 미달 12종 → 1종(스킬 등급 C 글자 4.3, 그대로 둠) |
| 너무 작은 글자 | 반영 | 글자 「작게」(기본)에서 실제 7~9px로 보이던 것: 메뉴 단추 글자 · 미션 등급 · 소식 띠 머리 · 연봉 총액 라벨 · 코치 칸 · 매물 줄 칩 · 순위표 PO 표시 · 등급 글자 등을 11.5px(실제 10px)로 올림. 정렬 화살표(▲▼⇅) 같은 기호는 그대로 |
| 창 제목 굵기 700 | 반영 | 선수 관리 메뉴 등 창 제목(h3)을 600으로 |
| 줄마다 노란 단추 | 반영 | 이적 → 내 선수 → 매물 등록 등 목록: 줄 오른쪽 작은 단추(「판매 등록」 · 「제안」 · 「협상」)가 전부 노란색이던 것 → 테두리만. 노란색은 그 화면의 큰 단추 · 고른 칸에만 |
| 감독실 노란 테두리 칸 | 반영 | 감독실 「첫 시즌 할 일」 · 「받은 소식」 칸의 노란 테두리 → 보통 테두리 + 왼쪽 노란 막대만 |
