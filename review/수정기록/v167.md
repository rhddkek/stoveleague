# v167 수정기록 — R138 (선수 창 「바로 하기」에 더 꺼내기)

- 저장 형식 그대로. 모두 `pActs`에 넣어서 카드 「바로 하기」 · 선수 상세 개요 · 「관리 ⋯」 창에 같이 나옴. 기능 자체(효과 · 조건)는 예전 화면과 같은 함수. 새 검사 `test/v167_r138.js`. 전체 실행에서 v82(구직 · 구인 화면)가 한 번 걸렸고 따로 세 번 돌려 모두 통과 — 이번 변경과 무관한 흔들림.

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 방침 | 반영 | 우리 타자 · 선발 카드 → 「방침」 → 창 「○○ 방침」에서 [맞히기 · 보통 · 크게 치기](선발은 강판 시점) 고르면 바로 바뀜. 예전 자리(선수 상세 → 능력)도 그대로 |

| 장비 | 반영 | 카드 「장비」 → 육성 → 장비 화면이 그 선수를 고른 채로 열림(육성군 선수는 장비 대상이 아니라 안 나옴) |
| 스킬 캠프 | 반영 | 겨울, 남은 자리가 있고 아직 안 보낸 선수 카드 「스킬 캠프」 → 코스 고르는 창 |
| 겨울 계획 | 반영 | 겨울 카드 「겨울 파견」(파견 대상 · 접수 중일 때) → 파견 구단 고르기, 「겨울 휴식」 ↔ 「동계훈련」 바로 바꿈 |
| 해외 진출 답 | 반영 | 해외 진출을 요청한 선수 카드 「해외 진출 답」 → 요청 창([거절 · 허락]) |
