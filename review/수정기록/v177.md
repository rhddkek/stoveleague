# v177 (R148) — 남은 약점: 문장 → 단어 · 리그 맞춤 · 조사

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 탭 화면 문장 → 단어 | 반영 | 위 탭 × 아래 탭 56화면(한국 시즌 중 · 일본 개막 전)에서 「~습니다 · ~하세요」 0줄. 예: 받은 제안 「받은 제안 없음 · 선수 카드 → 판매 등록」 · 결과 「끝난 협상 없음 · …」 · 명예의 전당 「헌액 선수 없음 · …」 · 겨울리그 「겨울 1~2주차 · 25세 이하 · 동계훈련 대신」 |
| 알림 문장 → 단어 | 반영 | 「라인업 저장」 「복사 완료」 「선수 정보 없음」 「공고 · 2일 뒤 답」 등 63개 → 문장 0개 |
| 소식 문장 → 단어 | 반영 | 「[FA] 이름 → 구단 · 2년 27억원」 「[복귀] 이름 · 햄스트링 회복 · …」 「[드래프트] 2026 후보 80명 공개 · 관찰 5명까지」 「[겨울리그] 파견 요청 3건 · 2주차 마감」 「2026시즌 종료 · 스토브리그 시작」 · 구장 특징 「우측 펜스 짧음 · 외야 바람 · 타구 ↑」 |
| 이적 제안 대화 | 반영 | 선수 카드 → 받은 제안: 「이름 · 이적료 24.7억원」 / 선수 「주전 출장 가능 · 이적 OK」 「… · 이적 싫음」 |
