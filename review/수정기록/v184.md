## 어떻게 쟀나

## 고친 것
| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 문장 → 단어(개조식) | 반영 | 화면 · 알림 · 소식 · 오류 문구 940곳을 「~함 · ~음 · 없음 · 불가 · 고르기」로(예: 「판매 등록할 수 없습니다」 → 「판매 등록 불가」, 「계약했습니다」 → 「계약」). 남은 문장은 대사뿐(협상 테이블 · 수훈 인터뷰 · 중계 · 「」 인용). 코드 기준 809 → 120곳(전부 대사) |
| TMI 줄이기 | 반영 | 샐러리캡 규정 4줄 표 · 스폰서 종류 설명(「3년 고정 · 성적 무관」 · 「1년 고액 · 목표 실패 시 반환」 · 「최고액 · 명문 구단 전용」, 9위 해지 경고는 한 번만) · 코치 맡기기 · 자동 진행 고르기(「일주일 · 중요한 일에 멈춤」) · 채용 공고 · 캠프 창 · 시범경기 · 다음 목표(「목표 목표 5위」 겹침 없앰) · 가을야구 탈락 창의 리그 방식 설명과 진출 팀 전체 목록(대진표와 겹침) 뺌 |
| 다른 리그끼리 소식 | 반영 | 미국 · 일본 · 대만 구단을 맡아도 한국 리그 부상 · 가을야구 · MVP · 퓨처스 · 2차 드래프트 소식이 쌓이던 것(미국 한 시즌 32줄 → 0줄, 소식 160줄 한도를 밀어내던 것). 우리 리그 구단 · 우리 선수 · 우리 출신 이름이 있으면 그대로(`newsOff`) |
| 시리즈 이름 | 반영 | 미국 구단 스폰서 「한국시리즈 진출 +878억」 → 「월드시리즈 진출」(`serKo` — 일본시리즈 · 대만시리즈) |
| 노랑 채움 하나 | 반영 | 머리줄 「▶ 경기 · ▶ 진행」(`.nextb`), 목록 줄 단추(파견 · 2군 등록 · 교환 후보 추가 · 판매 등록 · 광고판 계약), 고르는 카드 단추(스폰서 「○○과 3년 계약」), 감독실 「오늘의 결정 · 처리」, 전력 진단 「FA 찾기 · 해외 찾기」 = 노란 테두리. 채움은 그 화면의 주 단추(라인업 저장 · 훈련 적용 · 경기 보기 …) 하나. 밝은 색 테마도 같게 |
| 자동 진행 멈춤 | 반영 | 「이적 제안」마다 7경기 자동이 멈추던 것 → 매물 등록 선수 · 해외 공식 제안 · 시장가치보다 15% 넘게 부른 제안에서만 멈춤(`offerStop`). 나머지는 주간 보고서 「검토할 제안」 · 감독실 결정 줄 |
| 겨울 단계 안내 창 | 반영 | 해마다 4번(1 · 2 · 3 · 마지막 주) 뜨던 「스토브리그 n주차 — …」 창은 첫 겨울만(`S.stgN`), 그 뒤는 감독실 「이번 주부터」 카드 |
| 스프링캠프 이어 가기 | 반영 | 한 번 정한 캠프(`campLast`)는 다음 겨울 3→4주차에 그대로 적용 · 알림 「스프링캠프 · 작년과 같게 · ○○ 캠프 · ○○」 — 해마다 묻던 창 2장 없음 |
| 겨울 3주차 이름 | 반영 | 미국 구단 겨울 일정 띠 「2차 드래프트」 → 「룰5 드래프트」(일본 · 대만 「코치 계약」) |
| 경기 중 알약 | 반영 | 「할 일 n건 남음 · 다음 ▶」 알약이 경기 화면 아래 메뉴(선수교체 · 라인업)를 가리던 것 → 경기 중엔 숨김 |
| 트레이드 두 칸 표 | 반영 | 휴대폰에서 머리 「포지션나이능력잠재」가 겹치던 것 → 「위치」 · 이름 칸 44% |
