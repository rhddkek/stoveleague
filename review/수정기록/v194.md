# v194 (R166) — 육성 · 이적 · 구단 첫 화면 = 큰 그림 타일 (휴대폰)

벤치마크 정리 3단계. 아래 메뉴에서 육성 · 이적 · 구단을 누르면 표 · 탭 줄 대신 그림 타일이 먼저 나옴. 기능 · 화면은 그대로(한 번 더 누르면 예전 화면).

## 고친 것
| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 육성 첫 화면 | 반영 | 휴대폰 아래 메뉴 「육성」 → 큰 제목 + 타일 5개(훈련 · 성장 · 2군·유망주 · 겨울리그 · 장비). 타일 = 픽셀 그림 + 이름 + 상태 한 줄(「강도 보통」 「육성군 0/5」 「겨울에 열림」) + 안에 든 화면 이름. 단추 36 → 13 · 글자 571 → 106자 · 한 화면 |
| 이적 첫 화면 | 반영 | 「이적」 → 타일 4개(영입 · 내 선수 · 협상 · 결과). 상태 줄 「FA 40명」 「매물 0명 / 재계약 대상 n명」 「받은 제안 n · 진행 n」 「올해 n건」. 답할 제안 · 신인 지명 차례 · 재계약 대상이 있으면 그 타일 노란 테두리 + 노란 상태 줄. 단추 31 → 12 · 글자 957 → 145자 |
| 구단 첫 화면 | 반영 | 「구단」 → 건물 타일 9개(감독 · 재정 · 연봉·계약 · 스폰서·광고 · 시설 · 투자 · 구단 위상 · 옛 제자 · 설정·저장). 상태 줄 「3위 · 5승 4패」 「자금 479억」 「연봉 115억」 「메인 ○○」 「6곳 · 평균 Lv.0.5」 「신흥 구단」 — 모두 실제 값 |
| 오가기 | 반영 | 타일 → 예전 화면(위 탭 줄 그대로, 옆 화면으로 바로 옮김) → 아래 메뉴를 다시 누르면 타일. 묶음 타일(영입 등)은 마지막에 본 화면으로 들어감. 메뉴 · 찾기 · 할 일 단추로 바로 가는 길(`UI.go`)은 타일을 거치지 않음 |
| 그림 | 반영 | 픽셀랩 128×96 18장(`assets/art/hub_*.png`). 글자 · 로고 없음(헬멧 글자 · 구장 간판 글자는 픽셀로 지움) |
| 알림 | 반영 | 알림이 떠 있는 채 탭을 옮기면 머리줄 단추 자리가 달라져 「메뉴」를 덮던 것 → 화면을 그릴 때마다 다시 맞춤 |
| PC · 선수단 · 리그 | 그대로 | PC는 왼쪽 메뉴가 늘 있어 타일 없음. 선수단(명단이 곧 첫 화면) · 리그(순위표)는 그대로 |

## 판단
- 한 번 더 누르게 되는 값: 육성 → 훈련 목록까지 누름 1번 → 2번. 대신 첫 화면에서 「어디에 뭐가 있는지」가 그림으로 보임. 자주 가는 화면은 메뉴 바로가기 4칸 · 감독실 할 일 단추가 타일을 건너뜀.
- 첫 시즌 할 일(「이적 둘러보기」 등)은 타일이 아니라 안쪽 화면에 들어가야 끝남.
