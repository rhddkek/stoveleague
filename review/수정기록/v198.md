# v198 (R170) — 숫자 오류 · 부임 직후 연봉 · 써 보기 2탭 · 계속 단추 하나 · 해임 직후 감독실

GPT 두 시즌 후기(v197 · 타이중 31승 89패 → 대구 56승 88패, 두 번 해임). 순서는 광우 확인대로: 숫자 → 대만 · 부임 연봉 → 2탭 → 계속 단추.

## 고친 것
| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 확인 창 「연봉 0원 / 여유 0원」 | 반영 | 연봉 한도를 넘긴 상태에서 해외 후보 → 협상(구단 단계) → 확인 줄: 「연봉 한도 이미 279억원 초과 · 예상 연봉 11.2억원 → 290억원 줄여야」. 구단 단계에서도 선수 예상 연봉으로 계산(예전엔 0). 이적료 단계에서 막는 건 예전처럼 「이미 한도를 넘었을 때」만 — 여유가 있으면 요구 연봉은 개인 협상에서 다시 검사 |
| 예산 돌리기 · 연봉 정리 | 반영 | 돌리기로 메워지면 노란 「예산 돌리기 n번 · 이적 X → 연봉 Y」(한 번에 n번). 안 되면 노란 「연봉 정리 ›」 + 「예산 돌리기로는 부족 · 판매 · 방출로 연봉을 줄여야 함」 |
| 연봉 정리 뒤 그 선수로 | 반영 | 「연봉 정리 ›」 → 매물 등록 화면 맨 위 「‹ ○○ 협상으로 · 연봉 n 더 줄여야」(다 줄이면 「연봉 정리 끝 · 협상 가능」) → 누르면 그 선수 협상 |

| 부임 직후 연봉 한도 −55.7억 | 반영(원인) | 이직하면 예산을 새 구단 기준으로 다시 짬(`moveManager` → `S.budget=null`). 예전엔 떠난 구단 예산이 남아 새 구단 연봉 여유가 마이너스 |

| 써 보기 2탭 | 반영 | 개막 준비 끝 시범경기 창 「○○ 써 보기」 → 「안상민 A71 → 오정훈 C56 · 7번 · 3루수 · 시범경기 11타수 2안타」 + [타순 직접 편집 │ 기용]. 기용 = 같은 타순 · 같은 포지션(같은 포지션 주전 중 가장 낮은 선수 자리), 빠진 선수는 벤치. 선발 투수면 가장 낮은 선발 자리 · 빠진 투수는 불펜. 불펜 투수는 예전처럼 투수진 화면 |
