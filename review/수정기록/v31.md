| 제안 | 결과 | 무엇을 바꿨나 | GPT가 확인할 방법 |
|---|---|---|---|
| 1. 선수 카드를 게임 중심으로 | 반영 | **공통 선수 카드**: 초상 · 이름·나이·포지션 · 등급·종합·유형·성장 전망 · 크게 변한 능력 3개(↑↓) · 지금 역할(1군/2군 몫)·최근 기록 · 배지 · **코치 한마디**(콜업 후보·정체 원인·피로·최근 성장 요인 — 실제 기록에서만) · [선수 보기] [1군 등록 검토]. 육성 리포트의 콜업 후보·정체 주의, 관심 선수에 사용 | 홈 → 육성 리포트 타일, 관심 선수 타일 |
| 2. 홈 = 오늘의 감독 업무 | 부분 | 순서(구단·순위 → 오늘 경기 → 결정할 일 → 관심 선수 → 소식)는 v27부터 이미 이 구조. 「결정할 일」에 **콜업 추천**을 넣고, 누르면 바로 비교 화면으로 이동 | 2군 성적이 좋고 1군 주전과 비슷한 선수가 있을 때 홈 「결정할 일」 |
| 3. 1군·2군 이동 = 비교하고 결정 | 반영 | **1군·2군 이동 비교 화면**: 올릴 선수 vs 내려갈 선수(종합·변화·유형·강점·최근 기록·피로·예상 역할), 다른 선수로 바꿔 보기, 「바꾸면」 점검(수비 위치 가능·포수 아님·선발 체력·1군 정원), 확정하면 같은 타순·수비 위치/선발 순번/필승조를 그대로 넘겨받음. 이적·계약 기록 변화 없음 | 선수 카드 [1군 등록 검토], 선수 화면 「입단 이후」 카드의 버튼 |
| 4. 경기 화면 = 전광판 + 대결 | 부분 | 전광판·타자/투수 카드·큰 결과·접는 로그는 v24·v27에서 이미 반영. 이번에 **관심 선수·1군 데뷔전 표시**를 타자 카드에 추가(「★ 관심 · 1군 데뷔전」 + 오늘 기록) | 관심 선수(★) 지정 후 경기 보기 |
| 5. 성장 화면 = 이전과 지금 | 반영 | 선수 화면 맨 위 **「○○ — 입단 이후」**: 종합 입단 때 → 지금, 크게 변한 능력 2~3개, 역할 입단 때 → 지금(예: 벤치 야수 → 1군 벤치 · 2군 집중 육성), [영입 당시와 전체 비교] 버튼 | 우리 선수 화면 → 능력·성장 |
| 6. 이적 제안 = 공식 제안서 | 반영 | 「영입 제안서」: 「(해외 구단의) 공식 영입 제안」 띠, 구단 엠블럼 → 선수 초상, 대상·이적료(시장가치 대비 %)·보장 조건·이적 후 예상 역할·선수 의향·제안 기한·**우리 팀 영향**·**대체 후보**, [선수 의견 확인] [거절] [협상] [수락]. 열릴 때 짧게 떠오르는 연출만 | 이적 제안 도착 → 검토 |
| 7. PixelLab 순서 | 반영 | 초상(v24)·엠블럼(기존) 다음 순서인 **배지 4종** 제작·적용. 배지는 실제 기록에서만 생김: 1군 데뷔(첫 1군 경기), 첫 홈런(데뷔 뒤 첫 1군 홈런, 한 번만), 주전 정착(육성 성과 인정 시), 해외 진출(우리가 키운 선수가 해외로) | 선수 화면 배지 줄, 소식 「[첫 홈런]」 |
