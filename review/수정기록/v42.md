# v42 수정기록 — 모든 탭 한 화면 + 팝업 (R026)

- 작성: Claude · 2026-11-05 · 광우 요청: 「모든부분에서 한화면에 있으면 좋을꺼 같은데 밑으로 스크롤하지말고 ㅜ 팝업을 추가하는건 어때」 → 범위 「모든 탭」
- 원칙: 기능·밸런스·저장 형식 변화 없음. 화면에 다 들어가면 그대로, 넘칠 때만 아래 순서로 줄임
  1. 큰 그림 줄이기 — 경기장·감독실 그림, 「오늘의 구단」 카드(PC), 선수 상세 머리, 스토브리그 할 일 보드를 작은 모양으로
  2. **타일로 바꾸기** — 카드를 모두 타일(제목·요약 두 줄)로 바꾼 뒤, 앞에서부터 들어가는 만큼은 원래 카드로 되돌림. 타일을 누르면 그 카드가 **아래에서 올라오는 창(팝업)** 으로 열림. 팝업 안 버튼은 그대로 동작하고, 누르면 팝업 내용도 바로 갱신
  3. **주 작업 카드는 제자리** — 화면 절반 가까이 되는 목록(타순·수비 위치, 영입 후보, 코치 시장, 상대 선수 목록 등)은 타일로 숨기지 않고 그 카드 안에서만 스크롤
  4. 결정 카드(오늘 경기, 지명 차례, 트레이드 제안 내용, 결과 띠 등)는 타일로 숨기지 않음
- 함께 정리: 영입·스카우트 필터를 「🔍 검색·필터 / 조건」 접기 상자로(폰은 접힘, PC는 펼침, 적용 개수 표시) · 코치진 설명 두 줄 접기, 계약 기간 버튼은 코치 시장 안으로 · 트레이드 제안 카드의 현금·제안 버튼을 한 줄로 · 스토브리그 「다음 주로 / 시즌 개막(남은 주 건너뛰기)」 한 줄 · 드래프트 지명 버튼 3개 한 줄
- 안쪽 스크롤 위치 기억: 필터·체크를 바꾸거나 다른 탭에 갔다 와도 보던 목록 위치 유지. 창 크기·회전이 바뀌면 다시 배치(입력 중엔 안 건드림)
