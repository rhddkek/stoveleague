# v66 수정기록 — 등급 필터 버그 · 목록 조작 친화성 (R050)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 선수단 등급 필터 고르면 「선수가 없습니다」 | 반영(버그) | 선수단 → 선수 → 「능력치」 셀렉트에서 A등급: A등급 선수만 남고, 셀렉트에 「A등급」이 그대로 표시됨 (전에는 값이 「A등급」 글자로 들어가 아무도 안 맞고 표시도 「능력치」로 되돌아감) |
| 조건에 안 맞을 때 빈 화면 | 반영 | 필터 결과가 0명이면 「조건에 맞는 선수가 없습니다 + ✕ 필터 해제」 버튼. 필터가 걸려 있으면 필터 줄 끝에도 「✕ 필터 해제」 |
| 표 제목 눌러 정렬 (FM·프로야구 게임식) | 반영 | 선수단 표의 나이 / 능력치(종합) / 컨디션 제목을 누르면 그 기준 정렬, 다시 누르면 ▼▲ 바뀜. FA 표도 나이 / 등급 / 요구 조건 |
| 줄 두 번 누르면 상세 | 반영 | 줄 한 번 = 선택(조치 바 활성), 같은 줄 한 번 더 = 선수 상세. 표 아래 안내 한 줄 「○○ 선택됨 — 한 번 더 누르면 상세」. 선수를 고르는 모든 표(FA·훈련·유망주)에 공통 |
| 조치 바 고정 | 반영 | 폰에서 선수단 표를 스크롤해도 「상세 · 보직 · 2군 이동 · ⋯」 바가 하단 탭 위에 붙어 있음. 줄 높이 48px로 터치 여유 |
