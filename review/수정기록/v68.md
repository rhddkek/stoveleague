| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 1. 재계약 마감 보호 | 반영 | 스토브리그 2주차에 만료 선수가 남아 있으면 상단 「▶ 진행」이 빨간 **「⚠ 확인 N」**, 감독실 하단 버튼도 빨강 「확인할 일 N건」. 누르면 **「진행 전 확인」 창**: 「다음 주로 넘어가면 재계약하지 않은 N명이 FA로 떠납니다 (핵심 N명)」 → 핵심 선수(주전 ○○·N선발·마무리·핵심 유망주·팀 상위 가치) 먼저, 체크박스, 요구 연봉, 「선택 N명 재계약 시 연봉 +○ · 연봉 여유 ○ → ○」 → 버튼 **재계약 명단 정리 / 선택 N명 코치에게 위임하고 진행 / 그대로 진행 / 돌아가기**. 1주차·3주차 이후 평소 진행은 확인 없이 바로. 「남은 겨울 건너뛰고 개막」도 같은 확인(미계약 지명 신인 포함) |
| 1-2. 한 화면 유지·협상·결별 | 반영 | 이적 → **계약 관리 → 재계약 N**: 만료 선수 표(핵심 표시, 현재 → 요구 연봉) + 줄마다 **유지 / 협상 / 결별**, 「추천대로 채우기」, 아래 고정 막대 「유지 N명 (연봉 +○) · 협상 · 결별 · 미정 N / 연봉 여유 ○ → ○」 + **결정 실행**. 협상 고른 선수는 실행 뒤 협상 테이블로. 서운함 있는 선수는 「유지」 잠김(협상 필요). 감독실 「재계약 N명 · 핵심 N명 포함 [명단 정리]」에서도 바로 이동 |
| 2. 내 제안이 목록에 남음 | 반영 | FA가 「N주차에 결정하겠다」고 하면 이적 → **영입 현황 → 진행 중**에 「○○ · 결정 대기 · N주차 끝 발표 · 지금 2/4위 (○○ 앞섬)」 + **조건 올리기**. 이적 탭 기본 화면이 영입 현황(진행 중). 상단 탭 배지 = 진행 중 건수 |
| 2-2. 실패 이유 = 실제 판단 | 반영 | 결정 주에 지면 소식·결과에 「선수 평가 ○○ 106 : 우리 100 — 총액 ○ vs 우리 ○ · 연봉 ○ vs 우리 ○ — 선수는 해마다 받는 연봉을 총액보다 더 무겁게 봄(연봉×0.6 가산) · 계약금 · 주전 약속 · 친정 · 지난 시즌 순위」. 총액이 더 높아도 진 경우 「총액은 우리가 높았음 (33.8억 vs 33.4억)」으로 시작. 선수가 실제로 고르는 계산(faScore)과 같은 식 |
| 2-3. 개인 요구 vs 경쟁 구분 | 반영 | FA 협상 화면 아래 **① 개인 요구 충족/미달 (요구 N년 총액 · 연봉 · 계약금)** / **② 경쟁보다 앞섬·비슷·부족 (○○ N년 ○억, 선수 평가 우리 N : 100 — 96 이상이어야 검토)**. 거절 회신 화면에도 「방금 제시가 막힌 이유」로 같은 두 줄. 대리인 답도 「저희 요구는 채우셨지만, 선수는 그쪽 조건을 더 높게 봅니다」/「저희 요구(…)에도 못 미칩니다」로 구분. 회신 표 제목 「선수 개인 요구」 |
| 2-4. 결과는 우편함 첫 항목 | 반영 | 내가 협상한 선수의 결과(✅ 계약 / ❌ 다른 구단 선택 / ⏳ 결정 대기)가 감독실 「이번 주 결정할 일」 맨 위 + 수신함 맨 위(태그 「내 협상」). 「이유 보기」 = 위 설명, 계약 성공이면 배치 화면 |
| 3. 신인 계약 연결 | 반영 | 「계약하기」(감독실·우편함) → 이적 → 드래프트 화면 맨 위 **지명 선수 계약** 카드: 줄마다 계약/포기 + **N명 모두 계약 (합계)**. 드래프트가 끝난 뒤에도 이 카드가 먼저 나옴 |
| 4. 외국인 비용 일치 | 반영 | 후보 표 「첫해 비용 ○억 (연봉 ○+이적료 ○)」, 리포트·스카우트 보고서 「예상 연봉 ○ [추정] — 현 소속 연봉 ○의 1.3배(해외 선수는 지금보다 많이 원함)」, 「이적료 ○ [추정]」, 「첫해 총비용」. 협상에서 확인되면 [확인됨]. **목록 숫자 = 협상 첫 요구**(테스트로 5명 대조) |
| 4-2. 관찰 비용·기간 먼저 | 반영 | 버튼 「🔭 집중 관찰 2주 · ○만 / 지식 30% → 68%: 강점·약점 공개」. 관찰 중이면 「관찰 중 · N주 남음」, 100%면 「✔ 관찰 완료」(비활성) |
| 4-3. 정원 차면 협상 대신 교체 | 반영 | 외국인 정원이 차 있으면 버튼이 「정원 참 — 교체 대상 고르기」 → 우리 외국인 목록(능력·연봉·역할) + 방출 / 판매 등록으로. 방출하면 바로 협상 화면. FA 목록·선수 상세 등 어느 경로로 협상을 눌러도 같은 창 |
| 4-4. 「조건 문의」 이름 | 반영 | 후보 화면 버튼은 「📄 스카우트 보고서」와 「🤝 협상 시작 · 첫해 ○억」으로 나눔. 선수 상세 메뉴도 「영입 협상 — 예상 연봉 ○ + 이적료 ○ = 첫해 ○」 |
| 4-5. 진행 단계 한 표현 | 반영 | 영입 현황 줄마다 6칸 막대 + 「관찰 중 → 보고서 도착 → 구단 협상 → 선수 협상 → 계약 완료 → 배치 완료」 중 현재 단계. 관찰·보고서·FA 결정 대기·외국인 협상·배치 대기가 한 목록에 |
| 4-6. 입단 팝업 + 배치 하나로 | 반영 | 영입 계약이 끝나면 입단 팝업 없이 바로 **입단·배치 화면 하나**(기존 선수 비교 + 배치 제안). 영입 현황 「배치하기」도 같은 화면 |
| 5. 겨울 홈 = 이번 주 업무 | 반영 | 감독실(스토브리그): 맨 위 「스토브리그 N주차 · 다음 진행 시 …」 → **이번 주 결정할 일**(내 협상 결과, 재계약 마감, 신인 지명·계약, 받은 제안, 외국인 빈자리) → **진행 중인 영입** → **올겨울 보강 목표 3칸**(✅ 영입 완료 / ⏳ 진행 중 / 후보 찾기) → 접힌 「지난 시즌 결과 · 전력 진단 · 구단 소식」 → 하단 고정 「▶▶ 다음 주로 진행 (N주차 → N+1주차 · 남은 결정 N건)」 |
| 6. 이름 = 상세, 줄 = 선택 | 반영 | 모든 선수 표: **파란 밑줄 이름을 누르면 선수 상세**, 줄을 누르면 선택(아래 리포트·비교가 바뀜). 같은 줄을 다시 눌러도 상세로 튀지 않음. 선수단 안내 「이름을 누르면 상세, 줄을 누르면 선택」 |
| 6-2. 협상 입력 통일 | 반영 | 재계약·FA·영입 모두 같은 비교표(계약 기간·연봉·계약금·총액, 선수 희망 vs 우리 제안, −/+). 대리인 대화는 「이전 회신」 한 줄 + 「협상 대화 (N)」 접기 |
| 6-3. 「+5%」 → 「요구액의 105%」 | 반영 | 버튼 이름 「연봉 = 요구액의 95%」·「연봉 = 요구액의 105%」(누를 때마다 오르지 않는 고정값임을 명시) |
| 6-4. 뒤로 가면 그대로 | 반영 | 목록에서 선수 상세 → 뒤로: 스크롤 위치·선택 선수·필터·정렬 유지 (폰 확인: 600px 내려간 FA 목록 → 상세 → 뒤로 = 600px) |
| 6-5. PC 오른쪽 패널 | 반영 | 이적 탭: 이적 자금(구단 자금·이적 잔액·연봉 여유) + 진행 중인 영입 + 받은 판매 제안만. 겨울 감독실: 진행 중인 영입 + 보강 목표. 선수단: 줄을 고르면 맨 위 「선택한 선수」 카드(상세 보기) |
| 7-1. 오프시즌 날짜 | 반영 | 1주차 11월 3일 → 2주차 11월 10일 → … 7일 단위 |
| 7-2. 예산 명칭 | 반영 | 상단 바: 이적 화면 「이적 잔액 · 연봉 여유」, 선수단 「연봉 총액 / 예산」. 이적 패널 「구단 자금 / 이적 잔액 / 연봉 여유」 |
| 7-3. 선택 없는 「오늘의 결정」 | 반영 | 「훈련을 유지하겠습니다 — 확인/넘기기」 같은 코치 보고는 오늘의 결정에서 빠지고 코치 한마디·소식으로. 오늘의 결정은 실제 선택(기용·휴식 등)만 |
| 7-4. 성장 카드 1군/2군 | 반영 | 성장·명단 기록 줄에 「1군 타율 …」/「2군 …」/「1군 등판 없음」으로 어느 기록인지 표시 |
| 이적 탭 상단 메뉴 | 반영 | 영입 현황 / 선수 찾기(국내 구단·FA·해외·외국인) / 계약 관리(재계약·판매 등록) / 트레이드 / ⋯(협상 테이블·발굴·드래프트) |
| 7. 여백·색·연출 | 보류 | GPT 순서대로 흐름 안정 뒤 적용 |
