# v73 수정기록 — 구장 소리 (R057)

- npm test 18종 전체 통과. 실제 브라우저에서 한 경기(공 단위 40번 + 타석 단위)를 진행해 소리 호출 횟수를 셈: 관중 소리 1(반복) · 플레이볼 1 · 심판 스트라이크 7 · 볼 11 · 삼진 콜 11 · 아웃 콜 25 · 세이프 1 · 함성 6 · 홈런 함성 1 · 탄식 10 · 등장음 8 · 호루라기 4
- 소리는 ElevenLabs로 만듦(관중 함성·탄식·호루라기 응원·등장음은 효과음, 심판 콜은 「Play ball!」과 같은 목소리). 심판 콜은 받아쓰기로 확인해 같은 말이 두 번 나오는 부분을 잘라 한 번만 남김
- 한국어 「○○○ 안타!」·「○번 타자 ○○○!」는 선수 이름이 수천 개라 미리 녹음할 수 없어 **기기에 들어 있는 한국어 음성**(브라우저 음성 읽기)으로 읽음. 한국어 음성이 없는 기기에서는 조용히 건너뜀
- 효과음을 끄면 전부 꺼짐. 설정에 「심판 콜」·「장내 아나운서」 따로 켜고 끄기 추가

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 1. Play ball! 작게 | 반영 | 경기 보기 → 「Play ball!」이 v72의 절반 크기 |
| 2. 관중 소리 | 반영 | 경기 화면에 있는 동안 관중 웅성거림·막대풍선 박수가 계속 깔림(배경 음악 대신). 우리 안타 → 함성, 우리 홈런 → 큰 함성, 상대 홈런·우리 삼진·병살 → 「아~」 탄식. 우리 공격에 득점권 주자가 있으면 타석 시작 때 응원 호루라기+박수 |
| 3. 「○○○ 안타~」 | 반영(기기 음성) | 우리 안타·2루타·3루타·홈런 뒤 「○○○, 안타!」「○○○, 홈런!」을 기기 한국어 음성으로 읽음. 설정 → 「장내 아나운서」로 끄기 |
| 4. 클린업 등장음 | 반영 | 우리 3·4·5번 타자 타석이 시작될 때 짧은 등장 음악 + 「4번 타자, ○○○!」 |
| 5. 심판 콜 | 반영 | 「공」 단위로 진행하면 공마다 「Strike!」/「Ball.」, 삼진은 「Strike three, you're out!」(모든 단위), 아웃은 「Out!」(공·타석·장면 단위), 도루 성공 「Safe!」. 설정 → 「심판 콜」로 끄기 |
