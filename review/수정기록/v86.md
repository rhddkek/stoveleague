# v86 수정기록 — 경기 화면 연출: 구장 그림 · 타구 길 · 주자 달리기 · 스트라이크 존 (R070)

- npm test 25종 전체 통과. 새 `test/v86_r070.js`: 한 경기를 한 타자씩 진행하며 **그림이 기록과 같은지** 매 타석 확인 — 주자 이름표 수 = 실제 베이스 주자, 존의 공 수 = 실제 투구 수, 초록(볼) 수 = 볼카운트, 타구가 떨어진 쪽(좌/우) = 중계 문구(좌전·우중간·3루수 땅볼…), 390×844에서 작전지시 줄까지 한 화면
- **경기 결과·밸런스 변화 없음**: 그림용 기록은 난수를 쓰지 않음(타석·투구 번호로 정함). 같은 시드로 40일(유저 경기 40경기 포함) 돌린 결과가 v85와 **완전히 같음**(전 구단 승패·전 선수 기록 해시 일치). AI 구단끼리 경기는 그림용 기록을 아예 만들지 않음
- 세이브 형식 그대로(VERSION 6). 진행 중 경기에 새 칸(lg.fx·lg.pz·lg.evN)이 생기지만 없어도 그려짐(예전 저장 경기 확인)
- 확인 화면: `review/참고/v86_경기연출.gif`(실제 경기 3장면 움직임) · `v86_경기_390.png` · `v86_경기_pc.png` · `v86_장면별.png`(홈런·병살·삼진·희생플라이·도루 실패 그림만 — 위 결과 띠는 잘라냄)

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 1. 구장 그림 | 반영 | `?test=1` → 경기 보기. 가운데가 **위에서 내려다본 구장**(외야 잔디 부채꼴 · 노란 담장 · 내야 흙 · 파울선). 수비수 9명이 수비 팀 색 동그라미에 **P C 1B 2B SS 3B LF CF RF**. 주자는 공격 팀 색 동그라미 + 이름표(「이름 주82」= 주력), 타자는 홈 옆(왼손 타자는 1루 쪽), 왼쪽 아래 「타자 이름 / N번 · 타격 · 시즌 타율」 |
| 2. 타구 연출 | 반영 | 「다음 타석 ▶」을 누르면 공(흰 점)이 홈에서 날아감: 땅볼은 수비수 앞까지 + **노란 점선 송구**(병살은 2루 → 1루), 뜬공·장타는 공이 커졌다 작아지며 날아감, 홈런은 담장 밖 + **HOME RUN**, 삼진은 홈 옆 **K**. 주자는 베이스를 따라 달리고 홈인하면 **+1**, 아웃된 주자는 사라짐. 떨어진 곳에 동그라미가 남아 다음 타석 전까지 「어디로 갔는지」 보임. 방향은 중계 문구와 같음(예: 「우중간 가르는 2루타」 → 오른쪽 가운데 담장 앞) |
| 3. 스트라이크 존 | 반영 | 구장 오른쪽 가운데 작은 칸 「투구 N」: 이번 타석 공마다 번호 점 — 초록 볼 · 노랑 스트라이크 · 주황 헛스윙 · 회색 파울 · 파랑 인플레이. 타석이 끝나면 제목이 「직전 타석」. 「공 하나씩」으로 두면 공 하나마다 점이 하나씩 늘고 초록 점 수 = 위 B 불빛 수. 누르면 대결정보 |
| 4. 결과 띠·알림 | 반영 | 방금 결과는 구장 **맨 위 얇은 띠**(얼굴 · 이름 · 결과 · N아웃 / 해설 한 줄)로, 공이 떨어진 뒤 나타남 — 다이아몬드·주자를 가리지 않음. 「첫 시즌 할 일 1/6」 같은 알림은 경기 중엔 **화면 맨 위 한 줄**(예전엔 구장 가운데) |
| 덤. 감독실 한 화면 | 반영 | 결정·미션·볼거리 줄이 다 붙어 오늘 경기 카드가 길어진 날: 「오늘의 볼거리」 → 구장 줄 → 아래 타일 둘째 줄(알림 점 없는 것) 순서로 감춤. 360×600에서도 한 화면(테스트 중 가끔 360×740에서 넘치던 경우) |
| 참고 | — | 실책은 엔진에 아직 없어 그림에도 없음(광우 결정 대기 그대로). 「고전 화면」 설정(PREF 경기 화면=classic)은 예전 화면 그대로 |
