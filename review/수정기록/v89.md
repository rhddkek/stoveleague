|---|---|---|
| 1. FA 줄 → 상세 바로 | 반영 | 이적 → 선수 찾기 → FA: 줄을 누르면 「선수정보 / 협상 / 닫기」 창 없이 **선수 상세**가 바로 열림(★ 관심은 상세 위에, 협상은 아래 단추). 예전엔 줄 → 창 → 선수정보 → 상세 세 번 |
| 2. 주 단추 고정 | 반영 | 휴대폰 선수 상세: 아래 「📊 비교 · 🤝 FA 협상/영입 협상」(내 선수는 「⇄ 라인업/보직 변경」)이 화면 아래에 **붙어** 있어 스카우트 평가·보고를 내려가지 않아도 바로 누름. PC는 그대로(오른쪽 칸) |
| 3. 이 조건으로 계약 | 반영 | 협상 화면에서 「요구대로」(또는 결과 칸이 「✅ 수락 · 바로 사인」)이면 아래 단추가 주황 「제안 보내기」 대신 **초록 「✍ 이 조건으로 계약」** — 누르면 바로 계약·배치 화면. 선수가 더 바라거나 경쟁 중이면 「제안 보내기」 그대로 |

| 5. 관리 단추 | 반영 | 내 선수 상세 오른쪽 위 「⋯」 → 테두리 있는 **「⋯ 관리」** 글자 단추(육성군·판매·임대·재계약 등 8가지 창) |
| 5. 알림 자리 | 반영 | 「첫 시즌 할 일 1/6 — ✓ …」 같은 알림 띠: 휴대폰은 아래 탭 위 118px(단추 줄 위), PC는 아래 60px. 손가락이 통과해(pointer-events none) 단추를 막지 않음. v88에서 맨 위에 두었더니 화면 제목·돈 칸을 가림 |
