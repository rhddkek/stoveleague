# v93 수정기록 — unslop 전광판 방향: 「AI가 만든 티」 걷어내기 (R077)

- 세이브 형식·밸런스·기능·화면 순서 그대로(VERSION 6). **경기 화면(경기 시뮬레이션·코치 모드)은 하나도 안 바뀜**: 경기 중엔 `body.ingame` 이 붙고 새 규칙은 모두 `body:not(.ingame)` 아래에만 있음. v92 빌드와 경기 화면 요소 50종의 색·바탕·굵기·기울임·모서리·글자 크기를 비교해 차이 0
- 구조: 원래 `style.css` 는 그대로 두고 두 층을 얹음
  - `src/unslop_gen.css` — `tools/unslop_gen.py` 가 style.css 를 읽어 만듦(굵기 700~900 → 600 · 기울임 → 바로 · 작은 글자 음수 자간 → 0 · 모서리 3·5→4, 7·9→8 … · 어두운 테마의 남색 → 같은 밝기의 밤색 · 주황 바탕 흰 글자 → 어두운 글자). 다시 만들 땐 `python3 tools/unslop_gen.py`
  - `src/unslop.css` — 손으로 쓴 층(밤색 사다리 토큰 · 강조 노랑 하나 · 선택 회백색 · 표 머리 · 이름 · 오늘 경기 띠 · 전광판 숫자 · 알림 띠 · 밝은 테마)
  - 이모지 → 선 아이콘: `ui2.js` 끝의 `unslopIcons()` 가 화면·창·알림 글자에서 이모지를 찾아 같은 선 아이콘 한 벌(52종, 글자색을 따름)로 바꿈. 나라 국기는 「KR」 같은 작은 글자 칸. ★☆✓✕ 같은 글자 기호는 그대로
