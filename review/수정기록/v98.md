## 규칙 (이제 모든 화면이 이것만 씀)

| 역할 | 모양 | 예 |
|---|---|---|
| 영역 | 위 줄 큰 탭(밑줄) | 순위 · 일정 · 기록 … |
| 화면 | 아래 줄 칩 | 순위표 · 우리 팀 지표 |
| 화면 안 보기 전환 | **회색 상자 안 칸, 고른 칸만 밝게** | 1군/2군 · 타자/투수 · 투수단/타자단/수비… · 긴 화면 쪽 나누기 |
| 정렬·필터 | 아래 줄과 같은 칩 | 능력순 · 요구액순 · OPS · 북부/남부리그 |
| 화면 큰 제목 | 18px 한 가지 | FA 시장 · 해외 선수 찾기 · 영입 현황 |

| 항목 | 결과 | GPT가 확인할 방법 |
|---|---|---|
| 보기 전환 5가지 모양 → 1가지 | 반영 | 선수단 → 선수(「1군 26/26 · 2군」, 「투수 · 타자」) · 투수진(「투수단 · 타자단 · 수비/주루 · 상태 · 계약」) · 이적 → FA(「타자 · 투수」) · 리그 → 기록실(「타자 · 투수」) · 구단 → 재정(쪽 나누기) 모두 같은 회색 상자, 고른 칸만 밝음. 예전엔 큰 단추·붙은 칸·위만 둥근 파란 탭·번호 동그라미 칩이 섞여 「셋째 탭 줄」처럼 보였음 |
| 정렬·필터 칩 3가지 → 1가지 | 반영 | 이적 → FA 「능력순·요구액순…」, 해외 「추천·리그별…」, 리그 → 기록실 「타율·OPS…」, 2군 리그 「북부·남부」가 아래 줄 칩과 같은 모양 |
| 큰 제목 두 크기 → 한 크기 | 반영 | 「FA 시장」(예전 20px 가는 글씨)과 「영입 현황」(18px)이 같은 크기·굵기 |
| 같은 이름이 두 줄 | 반영 | 폰에서 긴 화면을 쪽으로 나눌 때 첫 쪽에 제목이 없으면 아래 줄 탭 이름을 또 쓰던 것 → 「현황」. 예: 육성 → 2군·임대 아래 「현황 · 유망주」(예전 「2군·임대 · 유망주」) |
| 구단 → 시설 겹침 | 반영 | 「구단 시설 | 구단 커리어」 전환 상자를 없애고 시설 현황 · 시설 개선 · 구단 커리어(전체 단계) · 감독 커리어 · 홈구장이 한 화면(폰은 쪽 나누기). 예전엔 전환 상자 + 쪽 칩 + 짧은·긴 커리어 카드 두 벌 |
| 경기 화면 | 건드리지 않음 | 광우 요청대로 경기 중 화면(body.ingame)은 이번 규칙 밖 |
