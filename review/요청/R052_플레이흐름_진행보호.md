# R052 — 플레이 흐름: 재계약 마감 보호 · 협상 결과 설명 · 영입 현황 · 이번 주 업무 홈 · 조작 통일

- 요청: GPT 플레이 테스트(v67, 대구 2시즌) + 광우 (2026-11-07) 「fa같은건 무조건 확인하고 넘길수있게 그런장치가 있어야지.... 다른게임 안해봤냐고!!!!!! 제발 쫌 찾아보고 공부하고 해줘야지」

## GPT 리뷰 원문

직접 한 시즌 돌리고, FA 협상과 외국인 영입·배치까지 해봤어. 불편하다는 느낌에 구체적인 이유가 있어.

지금은 색감이나 그림보다 “다음에 무엇을 해야 하는지, 누르면 무엇이 바뀌는지, 방금 한 일이 어디에 남는지”가 불분명한 게 더 큰 문제야. 기능은 꽤 들어 있는데, 그 기능들을 연결하는 플레이 흐름이 아직 정리되지 않았어.

AI의 한계라고 결론낼 상황은 아니야. 다만 화면을 하나씩 추가하는 방식으로 계속 만들면, 이런 불편이 누적되기 쉬워.

실제로 진행한 내용

v67의 대구 블레이즈 2시즌을 진행했어. 모든 경기를 수동으로 본 건 아니고, 경기 중 작전 선택 → 경기 종료 → 7경기 자동 → 남은 정규시즌 자동 진행을 섞었어.

테스트	실제 결과
정규시즌	68승 76패, 6위, 144경기 완료
포스트시즌	진출 실패 후 결과까지 진행
FA 포수 석영호	29억 제안 거절 → 4년 33.8억으로 재제안 → 최종 부산 선택
외국인 딜런 페레스	관찰 → 구단 간 이적료 협상 → 개인 계약
외국인 계약 완료	이적료 8.8억 + 1년 연봉 2.5억
영입 후 배치	1선발 등록 완료
신인 지명	일정 진행으로 자동 지명됐고, 이후 계약 진입 경로 확인

현재 테스트 세이브는 다음 시즌 개막 전, 스토브리그 4주차에 남겨뒀어.

1. 가장 먼저 고쳐야 할 건 ‘큰 손해가 나는 일정 진행’이야.

2주차에서 다음 주로 진행하자, 재계약하지 않은 선수들이 떠나면서 선수단이 35명에서 17명으로 줄었어.

재계약 마감 표시는 있었어. 하지만 중요한 선수들이 떠나는 마지막 순간에, 내가 확인한 흐름에서는 별도 최종 경고나 정리 화면이 없었어. 재계약 목록도 처음에는 ‘20건 더 보기’ 안쪽에 있었고.

이건 단순히 사용자가 꼼꼼히 읽어야 하는 문제가 아니야. 게임이 중요한 결정을 앞에 꺼내줘야 해.

바꿀 흐름은 명확해.

* 평소 일정 진행은 바로 실행.
* 계약 만료·지명권 상실 같은 큰 결과가 발생할 때만 진행 전 확인.
* “다음 주로 넘어가면 18명이 FA로 떠납니다.”
* 그중 주전과 핵심 유망주를 먼저 표시.
* 버튼은 재계약 검토 / 선택한 선수만 코치에게 위임 / 그대로 진행.

18명 각각의 대화창을 열어야 하는 구조도 피해야 해. 한 화면에서 유지·협상·결별을 정하는 명단이 먼저 필요해.

2. 협상 결과를 믿기 어려운 표시가 있어.

석영호에게 33.8억을 제안했는데 최종 소식은 다음과 같았어.

부산 33.4억 계약 — 우리 제시 33.8억보다 좋은 조건

총액 외에 연봉 구성이나 선수 선호가 작용했을 수도 있어. 코드를 보지 않았으니 계산 오류라고 단정하진 않겠어. 하지만 현재 설명은 사용자가 납득할 수 없어.

또 재제안 후 “3주차에 결정하겠다”는 회신을 받았는데, 이적 화면은 ‘진행 중 0건’이라고 표시했어.

이 두 가지는 시각 디자인보다 먼저 수정해야 해.

현재	바꿀 표시
진행 중 0건	석영호 · 최종 결정 대기 · 3주차 종료
우리보다 좋은 조건	실제 선택 이유: 연봉 구성·선수 선호·제안 평가 등
거절 후 선수 요구 30.1억, 경쟁 제안 33.4억	개인 요구 충족 / 경쟁 제안보다 부족을 구분
최종 결과가 소식 모음 안에 있음	내가 협상한 선수의 결과는 홈 우편함 첫 항목

협상은 성공 여부뿐 아니라, 실패 이유가 이해돼야 재미있어.

3. 외국인 영입은 ‘가격과 진행 단계’가 뒤늦게 드러나.

딜런 페레스를 영입하면서 본 금액이 이랬어.

화면	표시
후보 목록	요구 금액 9,800만
목록 아래 리포트	9,800만 + 합의금 8.7억
스카우트 상세	예상 연봉 9,800만
실제 개인 협상	선수 희망 연봉 2.5억
최종 계약	이적료 8.8억 + 연봉 2.5억

추정치와 실제 요구가 다를 수는 있어. 그런데 지식 100%인 보고서에서도 연봉 차이의 이유를 설명하지 않으면, 추정 시스템을 믿기 어려워.

후보 목록에서부터 최소한 이렇게 보여줘야 해.

딜런 페레스 · SP · 33세
1선발 후보 / 관찰 완료
예상 연봉 ○억 · 이적료 ○억 · 첫해 총비용 ○억

확인되지 않은 금액이면 추정, 구단·선수에게 확인한 금액이면 확인됨을 붙이고.

그리고 진행 상태는 한 가지 표현으로 통일하면 돼.

관찰 중 → 보고서 도착 → 구단 협상 → 선수 협상 → 계약 완료 → 배치 완료

지금처럼 관찰은 진행 중 목록 밖에 있고, FA 결정 대기도 목록 밖에 있으면 사용자가 기억으로 관리해야 해.

추가로 확인한 불편도 있어.

* 관찰 요청 비용 4,000만원이 누른 뒤에 드러남. 버튼 옆에 비용·기간을 먼저 표시해야 함.
* 외국인 정원이 차 있어도 협상 버튼이 활성화됨. 누르고 나서 막힘.
* 정원 초과 안내에 교체 대상 선택 연결이 없음.
* 처음의 조건 문의가 실제로는 스카우트 보고서를 엶.
* 관찰 완료 후에도 추가 관찰이 남아 있어, 더 무엇을 알게 되는지 불명확함.

반대로 영입 직후 기존 선수와 비교하고 바로 배치하는 기능은 좋아. 이건 살려야 해. 다만 입단 팝업과 오른쪽 배치 화면이 겹쳐 같은 결정을 두 번 제시하는 느낌이 있어, 하나로 합치는 게 좋아.

4. 스토브리그 홈은 ‘정보가 많은 대시보드’보다 ‘이번 주 업무 화면’이어야 해.

현재 홈에는 시즌 결과, 일정, 우편함, 전력 진단, 겨울 과제, 지난 시즌, 지금 결정할 일, 성장, 코치 의견이 함께 있어.

각각은 쓸모가 있어. 문제는 어느 것이 먼저인지 사용자가 다시 판단해야 한다는 것이야.

첫 화면은 다음 순서면 충분해.

위치	보여줄 내용
상단	스토브리그 2주차 · 다음 진행 시 재계약 마감
첫 번째	이번 주 반드시 결정할 일
두 번째	진행 중인 영입 — 관찰·협상·회신 대기
세 번째	올겨울 보강 목표 3개 — 포수, 선발, 외야
접힌 영역	지난 시즌 결과·성장·기타 구단 소식
고정 하단	다음 주로 진행 + 처리하지 않은 중요 업무 수

예를 들면 이렇게 읽히면 돼.

이번 주 마감
재계약 18명 · 핵심 선수 4명 포함
[명단 정리]

영입 진행
석영호 — 33.8억 제안, 다음 주 결정
딜런 페레스 — 관찰 완료, 협상 가능

올겨울 목표
포수 보강 / 선발 보강 / 외국인 교체

이렇게 바꾸면 글을 더 읽게 하지 않고도, 무엇을 해야 하는지가 보여.

5. 탭은 당장 줄이기보다 ‘각 탭에서 끝낼 일’을 명확히 해야 해.

이번에 핵심적으로 확인한 건 감독실·선수단·이적·경기 흐름이야. 육성·리그·구단의 모든 하위 기능까지 완주한 건 아니므로, 아래 후반부는 구조 제안으로 봐줘.

탭	이곳에서 끝낼 일	정리 방향
감독실	오늘/이번 주 결정 후 진행	마감·회신·주요 결과 중심
선수단	누구를 어디에 기용할지 결정	명단 → 비교 → 교체를 한 흐름으로
육성	누구에게 기회를 줄지 결정	성장 수치보다 훈련·출장·콜업 연결
이적	후보를 찾고 계약·배치까지 완료	영입 현황 / 선수 찾기 / 계약 관리
리그	우리 위치와 상대 확인	순위·일정·기록, 동일한 선수 상세로 연결
구단	예산·시설·스태프 관리	자주 안 쓰는 업무를 홈에서 분리

특히 이적 메뉴는 빈 받은 제안 화면을 기본으로 여는 것보다, 내가 진행 중인 영입부터 보여주는 편이 좋아.

재계약은 ‘더보기’나 여러 선수 상세를 돌아다닐 일이 아니라, 이적 탭의 계약 관리에서 일괄 정리할 수 있어야 하고.

6. 조작 규칙도 통일해야 해.

지금 선수단은 한 번 클릭하면 선택, 다시 클릭하면 상세인데, 다른 목록은 한 번 클릭하면 아래 리포트가 바뀌거나 오른쪽 상세가 열려.

협상도 FA는 비교표와 증감 버튼, 재계약은 대화와 숫자 입력창이어서 서로 다른 기능처럼 느껴져.

추천 규칙은 다음이야.

* 선수 이름을 누르면 항상 같은 선수 상세.
* 명단 선택이 필요하면 별도 체크박스.
* 상세 화면의 주행동은 현재 상황에 맞게 하나만 강조.
* 협상 입력은 기간·연봉·계약금·총비용 비교표로 통일.
* 대리인 대화는 최근 한 문장만, 과거 대화는 접기.
* 뒤로 돌아가면 검색 조건·선택 선수·스크롤 위치 유지.
* PC 오른쪽 패널은 선택한 선수/진행 중인 업무에 집중. 일반 구단 소식까지 함께 쌓지 않기.

또 연봉 +5%는 여러 번 눌러도 계속 올라가지 않았어. 요구 연봉 기준의 고정 설정이라면 **요구액의 105%**라고 써야 오해가 없어.

7. 발견한 추가 문제

* 지명 선수 계약하기를 눌렀는데 “드래프트는 끝났습니다”라는 결과 명단으로 이동했고, 도착 화면에서 계약 실행 버튼을 찾을 수 없었어. 연결 경로 점검이 필요해.
* 오프시즌 1주차 → 2주차에서 날짜는 11월 3일 → 11월 23일로 바뀌었어. 20일 단위라면 ‘주차’ 대신 ‘단계’를 쓰거나 날짜 진행을 맞춰야 해.
* 자금·이적 예산·연봉 예산이 다른데 상단에서 큰 금액을 그냥 ‘예산’이라고 부름. 구단 자금 / 이적 잔액 / 연봉 여유로 고정해야 해.
* ‘오늘의 결정’이 “훈련을 유지하겠습니다”에 확인/넘기기인 경우가 있었어. 선택이 없는 보고는 소식으로 보내야 해.
* 성장 카드의 ‘아직 타석 없음’과 2군 활약·성장 설명이 함께 나와 헷갈림. 1군 기록인지 2군 기록인지 명시해야 해.

반영 순서는 이렇게 잡는 게 좋아.

우선순위	수정 내용	완료 기준
1	재계약 마감 보호	중요한 선수 이탈을 모른 채 진행하지 않음
2	협상 상태·결과 설명	내 제안이 목록에 남고, 실패 이유가 일치함
3	신인 계약 연결	‘계약하기’에서 실제 계약을 끝낼 수 있음
4	비용·정원 사전 안내	누르기 전에 비용과 영입 가능 여부를 앎
5	홈 업무 순서 재배치	첫 화면에서 마감과 다음 행동을 찾음
6	명단·상세·협상 조작 통일	같은 행동은 어디서나 같은 방식
7	여백·글자·색·화면 연출	위 흐름이 안정된 뒤 적용

이번엔 새 시안 10장을 더 만드는 것보다, ‘재계약 정리 → 후보 비교 → 협상 → 계약 → 배치’ 한 흐름을 완전히 매끄럽게 만드는 게 효과가 커.

이미 전력 진단, 경쟁 제안, 성장 기록, 영입 후 배치까지 재료는 있어. 이제 사용자가 메뉴를 찾아다니지 않고, 결정 하나를 끝내면 다음 단계가 자연스럽게 이어지도록 묶는 작업이 필요해.
