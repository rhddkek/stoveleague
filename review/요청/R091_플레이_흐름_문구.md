## 2. 문구 줄이기 · 버튼은 행동 이름

| 지금 문구 | 줄이면 |
|---|---|
| 지난 시즌 결과 · 구단 우편함 | 시즌 결산 · 우편함 |
| 지금 결정할 일 | 처리할 일 |
| 상대 답을 기다리는 일 | 답변 대기 |
| 급하지 않은 일 | 선택 업무 |
| 우리 지명 차례입니다 | 우리 지명 |
| 코치 계약 만료 2명 | 코치 재계약 2명 |
| 포수 9위 → 후보 찾기 | 포수 9위 · 보강 › |
| 앞으로 2주 경기 · 큰 날 — 누르면 경기 전 준비 | 2주 일정 |
| 내가 정한 훈련·기용의 결과 | 훈련·기용 성과 |
| 최근 성장 점검 두 번 거의 제자리 | 2회 연속 성장 정체 |
| 선수를 누르면 이쪽에 상세 정보가 열립니다 | 선수 선택 |
| 영입 당시와 전체 비교 | 영입 전후 비교 |
| 자리까지 그대로 맞바꾸기 (선발 5번) | 맞교체 · 5선발 |
| 주전 지명타자로 배치 | DH 선발 배치 |
| 개막까지 건너뛰기 | 개막까지 ▶▶ |

결과 설명(넘기면 FA로 떠남 등)은 남기고 업무·기한·결과·버튼을 따로: 「재계약 20명 · 핵심 7명 / 2주차 마감 · 미계약 시 FA / [명단 정리]」

1. 버튼을 실제 행동으로: 겨울리그 파견 요청 → [파견 검토] · 광고 제안 → [제안 검토] · 광고판 빈자리 → [스폰서] · 코치 만료 → [재계약]
2. 겨울 업무는 ‘할 일 / 협상 중 / 완료’로 통일 (FA: 할 일 → 협상 중 → 완료 [배치] → 배치 완료 ✓, 완료 목록은 접기)
3. 협상 화면은 숫자 세 묶음(선수 요구 · 내 제안 · 경쟁 최고) → 기간/연봉/계약금 → [제안하기]. 재협상은 마지막 제안에서 시작, 제안 전엔 결과 표시 없음
4. 선수 등록은 「이동민 68 ↑ / 박용호 47 ↓ · 5선발 교체 · 1군 26/26 [교체 확정]」, 작은 옵션 ‘보직 유지’
5. 같은 소식은 가장 유용한 곳에 한 번만 (성장: 내 선수에 「이동민 68→75 · 제구 +13」, 이야기 카드는 첫 승·첫 완투 같은 사건)

## 3. 추가 의견 (첨부 원문)

여기서 핵심은 추천을 문장으로 끝내지 말고 바로 누를 수 있게 하는 것이야.
‘훈련 방향을 바꾸세요’를 읽고 육성 탭을 찾아가는 수고를 없애는 거지.

③ ‘다 봤음·닫기·확인’도 역할에 맞게 통일

플레이 중 자동 진행 보고서는 다 봤음, 경기 결과는 닫기로 나왔어. 둘 다 결과를 접는 동작이면 **접기 ∧**로 통일하는 게 자연스러워.

동작	버튼 이름
보고서만 줄임	접기 ∧
별도 창 종료	닫기 ×
설정 저장	적용
계약 제출	제안하기
계약 체결	계약 확정
명단 변경	교체 확정
다음 단계 진행	다음 지명 / 다음 주 / 개막

‘확인’을 누른 뒤 어디로 가는지 모르는 상황을 줄여야 해. 특히 드래프트 계약 완료 후에는 [확인]보다 **[다음 지명]**이 좋아.

④ FA·재계약·트레이드는 묶되, 처음부터 전부 펼치지는 않기

네가 말했던 “영입 관련 기능을 한곳에”는 이런 구성이 맞아 보여.

이적 화면 탭	내용
영입	FA·외국인·트레이드 후보
내 선수	재계약·판매·임대
협상 중 3	내가 보낸 제안·받은 제안
결과	영입·결렬·이적 내역

영입 안에서는 전체 / FA / 외국인 / 트레이드 필터로 바꾸고, 선수 상세를 열면 해당 선수에게 가능한 행동만 표시하는 거야.

예를 들어 FA 선수에게는 [협상], 타 구단 소속에게는 [트레이드 제안]. 사용자가 먼저 거래 방식을 찾아 들어갈 필요가 줄어들어.

⑤ 표에서 헷갈리는 숫자는 위치로 구분

등록 화면에서 ‘이동민 48’, ‘박용호 66’처럼 이름 바로 뒤에 등번호가 붙었고, 능력은 다른 열에 등급으로 나왔어. 빠르게 보면 그 숫자를 오버롤로 착각할 수 있어.

추천은:

선수	위치	능력	상태
이동민	SP	68 B	2군
박용호	SP	47 D	5선발

등번호는 선수 상세에 넣고, 교체 화면에는 능력 숫자를 우선 보여주기. 등록 결정에서는 등번호보다 전력 차이가 중요하니까.

⑥ 드래프트는 지명 후 흐름을 짧게 고정

실제로는 계약 → 훈련 선택 → 선수 상세로 넘어가면서 지명판을 다시 찾아가게 됐어. 이걸 작은 완료창 하나로 끝내면 돼.

이동민 · SP · 1R 1순위
계약금 5.7억 · 계약 완료 ✓
훈련 [추천: 제구 ▾]
[다음 지명]　[선수 상세]

나머지 선수 일괄 계약은 이미 편했어. 일괄 계약 기능은 유지하고, 개별 계약도 같은 지명판으로 돌아오게 하면 돼.

⑦ ‘시즌 끝까지’가 멈추면 다음 행동도 함께

자동 진행이 광고 제안 도착과 마감 때문에 멈췄어. 멈춘 이유는 보여줬지만, 처리하거나 무시하고 계속하는 흐름을 더 직접 연결하면 좋아.

자동 진행 중단 · 광고 제안 2건
[제안 검토] [무시하고 계속]

마감 직전이면:

광고 2건 · 오늘 마감
[제안 검토] [포기하고 계속]

이렇게 하면 사용자가 다시 ‘시즌 끝까지’를 눌러도 되나? 같은 일로 또 멈추나? 생각하지 않아도 돼.

⑧ 짧은 설명을 기본으로, 자세한 규칙은 눌렀을 때

예전 네 순위 화면 아래에 있던 긴 포스트시즌 설명도 같은 방식이야.

기본은:

5위까지 가을야구　[진출 방식 ⓘ]

눌렀을 때만 와일드카드 1승 이점, 시리즈 경기 수, 동률 기준을 보여주면 돼. 규칙을 없애는 게 아니라 매번 읽지 않게 하는 것.

내가 지금 가장 먼저 반영하고 싶은 건 이 네 개야.

1. 동일 용어 통일: 처리할 일 / 협상 중 / 완료.
2. 추천 옆에 실행 버튼: 훈련 변경·콜업·재계약으로 바로 이동.
3. 표의 숫자 정리: 등번호보다 능력·금액·기한 우선.
4. 작업 종료 지점 통일: 계약 뒤 지명판, 협상 뒤 협상 목록, 배치 뒤 선수단.
