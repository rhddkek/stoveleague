# R092 — 훈련·겨울리그·재정·시설·스폰서·재계약 화면 이름·순서 다듬기

- 작성: 광우(채팅, GPT가 v109 직전 판을 다시 열어 본 결과) · 날짜: 2026-11-10 · 게임 버전: v108~v109

## 원문

다시 들어가서 훈련·겨울리그·재정·시설·스폰서·FA·재계약까지 열어봤어. 더 나왔음ㅋㅋ 이번에는 단순히 긴 문구보다 “짧아도 헷갈리는 이름”과 “판단에 필요 없는 정보가 앞에 있는 것”이 눈에 띄었어.

아래는 방금 실제로 본 화면 → 수정 제안이야. 계약이나 예산은 건드리지 않았어.

1. 재계약 표에 계산 과정이 너무 많이 노출돼

선수 이름 아래 이런 내용이 붙어 있었어.

능력 -1 · 현 연봉+5% · 33세 −15%

이건 게임 내부 계산을 읽는 느낌이야. 기본 목록에서는 이렇게만 보여도 충분해.

선수	역할	현재 → 요구	결정
장규민	마무리	4.5억 → 4억 ↓	미정
홍재민	주전 3루	3.2억 → 11.2억 ↑	미정

계산 이유는 금액을 눌렀을 때 ‘요구액 근거’로 열기. 목록에서는 누굴 잡을지, 얼마인지가 먼저 보여야 해.

2. ‘유지’는 재계약 상태 이름으로 애매해

현재는 요구승낙 (유지)를 고르고, 아래 요약에는 유지 0 · 협상 0 · 결별 0이 나와.

‘유지’가 기존 연봉 유지인지, 선수 잔류인지 순간 헷갈려.

현재	제안
요구승낙 (유지)	요구액 수락
유지 / 협상 / 결별	수락 / 협상 / 결별
결정 칸 -	미정 ▾
추천대로	추천 선택
전체 요구승낙	전원 수락 선택
결정 실행	선택 적용

특히 ‘선택’과 ‘적용’을 구분해줘야 바로 계약되는 버튼인지 안 헷갈려. 적용 전에는 수락 8 · 협상 5 · 결별 7 / 연봉 +12억처럼 결과를 보여주고.

3. 재계약 결정 때문에 선수마다 창을 열 필요가 없어

지금은 선수 클릭 → 작은 창 → 수락·협상·결별 선택이야.

결정 칸의 [미정 ▾]에서 바로 선택하면 훨씬 빨라. 이름을 누르면 선수 정보, 결정 칸을 누르면 계약 결정. 20명을 정리할 때 차이가 커.

모바일에서는 작은 팝업이나 아래 선택창으로 띄우면 되고, 목록 위치는 그대로 유지하면 돼.

⸻

4. 훈련 화면은 제목이 네 번 겹쳐

실제로 육성 → 훈련·성장 → 훈련 설정 → 주간 훈련 설정이 이어지고, 아래에 “선수별 훈련을 배정하고…”라는 설명이 또 있어.

이렇게 줄이면 돼.

훈련　1주차
강도　[가볍게] [보통] [집중]
[전체] [유망주] [투수] [야수]

‘훈련 설정’과 ‘주간 훈련 설정’을 둘 다 보여줄 이유가 없어.

5. 훈련 숫자는 ‘언제까지의 변화’인지 밝혀야 해

표에는 변화(예상) +7, 선수 상세에는 제구 72→75 (+3), 옆 성장 점검에는 **개막 대비 +7**이 보여.

값이 틀렸다는 뜻은 아니야. 기간과 대상이 달라 보이는데 제목이 그 차이를 설명하지 못해.

숫자의 의미	붙일 이름
개막부터 현재까지 실제 종합 변화	시즌 성장
다음 주 훈련 예상치	주간 예상
선택한 능력의 예상 변화	제구 72→75

‘예상’과 ‘실제’를 색만으로 구분하지 말고 제목으로 구분하는 게 좋아.

6. 훈련 표의 ‘선수’ 열에는 포지션이 들어가 있어

현재 열이 선수 / 이름 / 집중 훈련 / 변화(예상) / 피로인데, ‘선수’ 아래 내용이 SP·RP·C야.

→ 포지션 / 선수 / 훈련 / 시즌 성장 / 피로

이런 작은 이름 불일치가 누적되면 화면을 읽는 속도가 느려져.

⸻

7. 겨울리그는 ‘최선 파견지’보다 ‘추천 구단’

현재 문구	제안
최선 파견지	추천 구단
파견지 고르기	구단 선택
파견 갈 구단	파견 구단
결정 기간 · 0/4명	파견 0/4 · 2주차 마감
성장 국내보다 높음	성장: 국내보다 유리
겨울을 보내는 세 가지 방법	겨울 계획

그리고 ‘리그 수준 미달’은 꼭 고쳐야 해. 선수 실력이 리그에 못 미친다는 뜻이라면 ‘선수 수준 부족’, 반대라면 ‘리그 수준 낮음’. 지금 문구만으로는 주어가 없어.

8. 겨울리그 설명표는 기본 화면에서 접어도 돼

현재는 파견·국내훈련·휴식의 장단점 표가 먼저 나오고 그 뒤에 구단 10곳이 나와.

처음에는 이렇게:

겨울 계획　[국내훈련] [해외파견] [휴식]
[방식 비교 ⓘ]

해외파견을 고르면:

구단	예상 역할	성장	비용
브리즈번	주전 경쟁	국내보다 유리	1.5억
시드니	백업	국내보다 불리	1.5억

피로·컨디션 불이익은 선택 구단 아래 한 줄로 남기기. 장단점은 보존하면서 매번 설명표부터 읽는 과정을 줄이는 거야.

⸻

9. 재정 화면은 ‘잔액’과 ‘여유’가 서로 다른 돈이라는 걸 더 명확히

지금 현금 896억 / 이적 잔액 135억 / 연봉 여유 74.4억 / 샐러리캡 여유 103억이 나와.

처음 보면 “돈이 이렇게 많은데 어떤 돈을 쓰는 거지?” 싶을 수 있어.

현재	제안
현금	보유 현금
이적 잔액	영입 예산
연봉 여유	추가 연봉 한도
샐러리캡 여유	캡 상한까지

구단이 허용한 연봉 예산과 리그의 샐러리캡은 서로 다른 제한이니까 한 덩어리처럼 보이면 안 돼.

10. 재정에 같은 금액을 여러 번 보여주고 있어

사용 52.6억 → 예산 사용 현황 → 52.6억(선수단 연봉) → 선수 연봉 52.6억(41%)처럼 반복돼.

하나로 충분해.

연봉 예산　52.6 / 127억
사용률 41% · 추가 가능 74.4억

다른 구단 캡 비교, 장기 보장액, 수입·지출은 각각 탭이나 접는 항목으로. 한 화면 안에서는 현재 필요한 하나를 보게 하고.

11. 샐러리캡은 현재 문제를 먼저

지금은 상한 여유 103억이 크게 보이지만, 동시에 하한에 8.3억 부족한 상태야.

이 상황에서 가장 먼저 보여줄 것은:

연봉 하한 미달 · 8.3억 부족
산정액 55.4억 / 하한 63.7억　[규정 ⓘ]

긴 세율·연속 초과·드래프트 불이익 설명은 규정 안으로. 단, 재계약 전이라 금액이 바뀔 수 있다는 점은 ‘현재 계약 기준’으로 짧게 표시.

12. 예산 전환의 ‘횟수’보다 바뀌는 금액을 중심으로

현재 전환 횟수 ▼ 1 ▲인데 실제로 궁금한 건 횟수가 아니잖아.

연봉 예산 늘리기
영입 예산 −15억 → 연봉 한도 +5억
[전환] · 이 방향 3회 남음

횟수 제한은 작은 보조 정보로, 얻는 돈과 잃는 돈은 크게.

⸻

13. 시설 효과는 괄호 설명보다 전후 비교

현재:

성장 속도 +12% (기존 속도 +0%)
피로 회복 16/일 (기존 회복 14/일)

추천:

훈련장 Lv.1 → 2
성장 보너스 0 → 12%
일일 회복 14 → 16
건설 10억 · 유지 시즌당 1.5억
[증설 · 10억]

구단 시설 / 구단 시설 현황 / 시설 개선 / 훈련장 레벨 업도 ‘훈련장 Lv.1→2’ 한 제목으로 정리 가능해.

14. 시설 화면에 커리어 목표가 끼어 있어

시설 개선 아래에 첫 시즌 완주 → 가을야구 → 우승 → 명예의 전당…이 나와.

이건 시설 결정과 직접 연결되지 않으니 감독실의 커리어 띠로 모으는 게 맞아. 시설 화면에는 효과·비용·유지비·구장에 집중하면 돼. 이건 글자 축약보다 공간 절약 효과가 커.

15. 스폰서는 ‘고정 수입’과 ‘예상 수입’을 같은 기준으로 비교

현재는 고정형 10억과 홈 입장 수입의 16%(예상 약 11.7억)이 섞여 있어.

업체	방식	수입
파랑항공	고정	10억
별빛제과	관중 연동	예상 11.7억

계약 기간 기준을 명시하고, 입장 수입의 16%라는 계산식은 상세로. 예상 금액에는 반드시 ‘예상’을 남겨야 하고.

선수 광고도:

인기 점수 상위: 이동민 11.1 · 홍재민 9.8 · 이태양 7.4 (8 이상이면 제안 가능)

대신:

광고 제안 가능 2명　[선수 보기]

상세에서 인기 점수와 기준을 보여주면 돼. 제안 가능과 실제 제안 도착은 구분하고.

⸻

이번에 제일 크게 느낀 건, “설명·계산 근거·행동”이 같은 높이로 나오는 게 문제라는 거야.

* 기본 화면: 누구 / 얼마 / 언제 / 무엇을 할지
* 눌렀을 때: 비교 / 이유 / 규정
* 확정 직전: 비용 / 바뀌는 상태 / 포기하는 것

그리고 모든 문장을 없애진 말자. ‘첫 승을 거뒀습니다’ 같은 선수 이야기는 남기고, ‘선수별 훈련을 배정하고 주간 육성 변화를 확인합니다’ 같은 사용 설명부터 덜어내는 게 좋아. 네가 원하는 간결함과 선수에게 정드는 재미를 같이 살릴 수 있어.

## 추가 2 (같은 날 첨부) — 메뉴·선수 상세·재정·감독 화면 문구와 표시 규칙

ㅇㅇㅋㅋ 이번엔 앞에서 덜 다룬 문구까지, 바로 바꿔 넣을 수 있게 더 뽑아볼게. 실제로 확인했던 표현을 기준으로 했어.

메뉴·버튼은 이렇게 더 정리할 수 있어.

현재	변경안
훈련·성장	훈련 / 성장으로 구분
훈련 설정	훈련
성장정보	성장 기록
