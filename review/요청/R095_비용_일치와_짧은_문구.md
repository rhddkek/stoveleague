# R095 — 계약 비용 일치 → 협상 버튼 고정 → 용어 통일 → 중복 문구 삭제 → 상황별 결산 문구

- 작성: GPT (광우 전달) · 날짜: 2026-11-11
- 게임 버전: v111 (모바일 화면 버튼으로 한 시즌)
- 환경: PC 「휴대폰 화면으로 보기」 · 대구 82승 62패 · 정규시즌 2위 → 한국시리즈 우승 · FA 황선우 거절→재협상→2년 연봉 2.4억→벤치 배치
- 이번엔 검토만 (코드 수정 없음)

## 방향
- 겨울 첫 화면(할 일 → 보강 포지션 → 다음 주)처럼 간결하게. 화면을 늘리기보다 중복 문구와 클릭을 뺄 것
- 선수 인터뷰·협상 대사는 문장 그대로. 버튼·상태·조건만 짧게

## R095-1 · 계약금 표시가 서로 다름 (높음)
- 제안표 계약금 0, 계약 완료엔 「계약금 1.6억 지출」. 하단 지출액은 있었지만 조건표와 안 맞음 → 항목명 통일

## R095-2 · FA 협상 핵심 버튼이 아래로 밀림 (높음)
- 모바일에서 「제안하기」가 아래에 걸침. 상단 요구액·제안액과 조건표가 같은 금액 반복, 남은 횟수도 두 번 → 중복 요약 줄이고 하단에 취소 / 제안 고정

## R095-3 · 진행 방식 변경에 클릭 하나 더 (보통)
- 진행 방식 → 경기 끝까지 선택 → 닫기 → 경기 끝까지. 고르면 창이 닫히게, 실제 진행은 메인 버튼

## R095-4 · 같은 능력치 이름 통일 (보통)
- 선수 검색 「오버」, FA 목록 「능력」, 상세 「종합」 → 종합. 위치 / 포지션 → 포지션

## R095-5 · 시즌이 끝나도 문구가 상황을 못 따라감 (보통)
- 우승했는데 결산 대표 문장 「2위, 가을야구까지. 선수들도 자랐습니다」 → 우승 시즌이면 「대구, 첫 시즌 한국시리즈 우승」. 시즌 종료 후 「이 페이스면」 빼기

## R095-6 · 겨울 숫자 세는 단위 (낮음)
- 「선택 사항 2건」 아래 「스폰서 제안 4건 · 광고판 빈 자리 5곳」 → 「선택 업무」라고만
