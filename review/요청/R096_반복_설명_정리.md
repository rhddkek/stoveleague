# R096 — 같은 정보를 제목·요약·설명에서 반복하지 않기

- 작성: GPT (광우 전달) · 날짜: 2026-11-11
- 게임 버전: v113 (같은 모바일 저장 · 드래프트 지명·계약, 해외 보고서, 이적료 협상, 코치 재계약, 재정, 판매 목록)
- 원칙: 한 화면 유지 · 「무엇을 누르는지 설명하는 말」은 빼고 「누르면 무엇이 달라지는지」만. 이번에도 검토만

## 우선 반영 세 가지
1. 해외 보고서의 중복 평가 삭제 — 관찰·협상 버튼을 위로
2. 코치 조작 안내를 버튼 이름으로 대체 — EMPTY를 코치 영입으로
3. 판매 목록에서 가격 확보 — 긴 기록 때문에 가격이 밀리지 않게

## R096-1 · 해외 스카우트 보고서
- 종합 의견 · 강점 · 우려 · 종합 평가(「체력는」 조사 오류 포함)가 반복 → 종합 평가 삭제, 첫 요약 두 줄: 「1선발 후보 · 신뢰 낮음」 / 「강점 체력 · 우려 구위」
- 문구: 현 소속 투수와 비교 → 우리 투수와 비교 · 대안 후보 (쇼트리스트) → 대안 선수(접힘) · ☆ 관심 선수 (관찰 명단) → ☆ 관심 등록 · 신장 195cm | 체중 97kg → 195cm · 97kg(선수 상세로) · 지식 10% → 관찰도 10% · 「강점 · 초기 추정 / 우려 · 초기 추정」 → 강점 / 우려 + 위에 「초기 평가」 한 번 · 「지식 10% → 86% 이상 · 강점·우려 확인」 → 「관찰도 10% → 86% 이상」
- 관찰 비용·2주 소요·추정치 표시는 유지

## R096-2 · 코치
- 조작 설명 문단 삭제, 버튼 이름으로: EMPTY 빈자리 2 → ＋ 코치 영입 · 공석 2 · 부서 효과 중복 설명 삭제 · 「잠재력 판별 정확도, 유망주·드래프트 발굴 — 영입 ›」 → 도움말에만 · 1년 남음 → 잔여 1년 · 재계약 2년 → 2년 재계약 · 「판별 정확도 +0%p · 매주 0명 정밀 관찰」 → 「정확도 +0%p · 관찰 0명/주」
- 「같은 부서 둘째부터…」 → 「동일 부서 추가 고용 시 효과 감소 ⓘ」
- 홈 「재계약」 단추로 들어오면 만료 코치를 맨 위에

## R096-3 · 드래프트
- 내 차례 / 지명 / 우리 차례 겹침 → 「우리 지명 · 1R 9순위」 한 번
- 계약 조건 (예상) + 계약금(사인보너스) → 예상 계약금 4.5억 · 내 관심 (0) → 관심 0 · 이번 차례 자동 → 이번 지명 자동 · 남은 4차례 자동 → 남은 지명 자동 · 다음 지명 (우리 차례) → 다음 지명 · 지금 47 · 잠재 B~S → 종합 47 · 잠재 B~S · 훈련 (추천 ★ 변화구) + ★ 버튼 → 제목 훈련, 버튼에만 ★
- 「구위가 돋보입니다. 변화구를 다듬으면 1~3선발까지 봅니다.」는 유지

## R096-4 · 해외 이적료 협상
- 이적 합의금 · ○○ 요구 약 8.6억 → 요구 이적료 약 8.6억 · 이적료를 내면 남는 자금 → 지급 후 현금 · 그 뒤 개인 협상 (연봉·계약금 별도) → 다음: 개인 협상 · 연봉·계약금 별도 · 이적료 제안하기 → 이적료 제안 · 자리에서 일어나기 → 협상 중단 · 중단 안내 → 「협상 중단 · 재협상 가능 1회」(실제 남은 횟수)

## R096-5 · 재정·판매
- 연봉 예산/샐러리캡 설명 → 「연봉 예산 = 구단 한도 / 샐러리캡 = 리그 한도」 · 지금 계약 기준 → 현재 계약 기준 · 운영비 (시설·…) → 운영비 ⓘ · 재계약할 만료 선수가 없습니다 → 올해 만료 선수 없음 · 등록 안내 → 판매 등록 후 제안 대기 · 등록할 선수 고르기 → 판매 후보 · 등록 → 판매 등록
- 판매 목록: 이름·포지션·종합·가치·등록 우선, 시즌 기록은 선수 상세로 (가격이 말줄임으로 숨지 않게)
