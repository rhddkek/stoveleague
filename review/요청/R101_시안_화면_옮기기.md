# R101 — GPT 시안 화면을 게임에 옮기기

- 작성: 광우 (채팅, 시안 그림 10장) · 날짜: 2026-11-11
- 게임 버전: v118

## 요청
GPT가 만든 화면 시안(선수단 명단 · 감독실(겨울) · 투수진 · 타순·수비 · 스카우트 보고 · 영입센터 · 신인 드래프트 · FA 협상 · 구단 재정 · 경기 화면)을 그대로 따서 넣기. 「전체적으로 눈에 잘 안 들어오고 복잡하다 → 더 직관적이고 쉽게」(R100-7)의 답.

## 순서
- 1차(v119): 전체 스킨 + 선수단 명단 + 겨울 감독실
- 다음: 투수진 · 타순 → 영입센터 · FA 협상 · 스카우트 보고 → 드래프트 · 재정 → 경기 화면

## 그대로 못 옮기는 것
- 재정 시안의 다이아(4,980 ＋) — 게임에 없는 재화, 뺌
- 타순 「좌투 상대 / 우투 상대」 · 영입센터 「의향」 칸 — 기능이 없어 화면 먼저, 기능은 따로 확인
- 시안마다 다른 아래 메뉴 아이콘·머리줄 — 한 가지로 통일
