# R106 — FA 보상 선수 · 2차 드래프트 (새 제도)

- 요청: 광우 (2026-11-12) — 「보상선수 제도가 실제로 있는가? 확인하고, 2차 드래프트도 있었던 거 같은데」
- 상태: 반영 (v132)

## 실제 제도 확인 (한국 프로야구, 2026-11 검색)
### FA 보상 (등급제)
| 등급 | 보호 선수 | 보상 | 
|---|---|---|
| A | 20명 | 보상 선수 1명 + 전년 연봉 200%, 또는 전년 연봉 300% |
| B | 25명 | 보상 선수 1명 + 전년 연봉 100%, 또는 전년 연봉 200% |
| C | — | 보상 선수 없음 · 전년 연봉 150% |
- 등급 기준: A = 최근 3년 구단 연봉 1~3위이면서 전체 30위 안 / B = 구단 4~10위이면서 전체 31~60위 / C = 그 아래, 또는 35세 이상 첫 FA. 세 번째 FA는 자동 C.
- 보상 방식(선수+돈 / 돈만)은 원 소속 구단이 고른다.

### 2차 드래프트
- 격년(2년에 한 번) 11월. 구단마다 보호 선수 35명, 그 밖의 선수를 다른 구단이 지명.
- 지명 구단이 원 소속 구단에 양도금: 1라운드 4억 (뒤 라운드는 더 낮음 — 2023년 기준 2R 3억 · 3R 2억 · 4R 이하 1억).
- 지명 선수는 다음 1~2시즌 안에 1군 의무 등록.
- 2025년 11월에 17명이 옮김.

## 게임에 넣을 때 (제안 — 실제 규정 그대로, 이름만 게임 리그)
1. FA 보상: FA에 A·B·C 등급 표시(연봉 순위 기준). 다른 구단 FA를 영입하면 원 소속 구단이 「보상 선수 + 돈」 또는 「돈만」을 고름. 우리가 영입하면 보호 명단(20/25명) 화면 → 상대가 1명 지명. 우리 FA가 떠나면 상대 보호 명단 밖에서 우리가 1명 고름(시안 「보상 선수」 화면).
2. 2차 드래프트: 짝수 해 스토브리그에 한 번. 보호 35명 고르기 → 성적 역순 3라운드 지명 → 양도금 4억/3억/2억.
3. AI 구단도 같은 규칙. 넣기 전후 FA 이동 수·구단 전력 변화를 수정기록에 적음.
