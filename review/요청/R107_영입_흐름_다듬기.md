# R107 — GPT 제안: 영입 흐름 다듬기 (찾기 → 비교 → 계약 → 배치 → 활약 확인)

- 요청: 광우가 GPT 의견을 붙여 줌 (2026-11-12). v123 플레이 기준 — 오늘 수정본(v124~v130)을 본 평가는 아님
- 상태: 접수

## 원문

나라면 기능을 더 넣기 전에, 지금 있는 ‘선수 찾기 → 비교 → 계약 → 배치 → 활약 확인’을 매끄럽게 연결하겠어. 스토브리그라는 제목에 맞게 겨울에 팀 만드는 과정이 가장 재밌어야 하니까.

아래는 직전 v123 플레이에서 확인한 문제 기준이야. 오늘 수정본을 새로 확인한 평가는 아니고.

1. 먼저 고칠 것 — 누른 행동과 결과가 일치하게

확인한 문제	내가 고칠 방식
드래프트 후보에게 FA·영입 협상 표시	신인 후보 상태로 분리. 버튼은 관심 · 지명만
신인 능력에 구속 −3 표시	생성·성장·표시 계산을 확인하고 정상 범위 검증. 숫자만 가리진 않기
후보 상세를 보다가 지명 대상이 헷갈림	상세를 닫아도 선택 유지. 하단에 구서진 지명 고정
작전 지시 후 해당 타석 결과가 지나감	지시한 타석은 반드시 보여주고, 확인 후 자동 진행 재개
‘예산 안’에 영입한도 초과 선수 노출	영입 비용과 연봉 여유를 모두 충족하는 선수로 필터

이건 꾸미기보다 먼저야. 숫자와 선택을 믿을 수 있어야 유저가 고민하고 결정해.

2. 선수 영입은 한곳에서 끝내기

하단 이적 안을 이렇게 정리하겠어.

상단 메뉴	모을 기능
영입	국내·FA·외국인·트레이드 후보
내 선수	재계약·방출·판매·임대
협상	제안 중·회신 도착·재제안
결과	영입·결렬·이적 기록

드래프트는 겨울 감독실의 **드래프트**로 바로 들어가되, 후보 비교와 선수 상세 모양은 영입 화면과 통일해. 성격이 다른 업무를 한 목록에 억지로 섞진 않겠어.

영입 화면 맨 위에는 설명 대신 이것만:

보강: 선발 · 포수　｜　영입 129억　연봉 11.5억

선수 목록은 이름·포지션·능력·예상 비용까지만. 나이·잠재력 등은 선택한 정렬이나 상세에서 확인하게.

3. 비교·협상은 ‘결정에 필요한 정보’만 남기기

선수를 누르면 맨 먼저 우리 선수보다 무엇이 나은지 보여주겠어.

비교	현재 선수	영입 후보
능력	68	74 ↑6
역할	3선발	2선발 후보
연봉	5억	8억

그 아래 관심 · 비교 · 협상. 상세 능력·기록은 기존 탭에 두고.

협상 첫 화면은 딱 네 덩어리로:

* 선수 요구 / 내 제안: 기간·연봉·계약금
* 추가 조건 ▸: 인상률·바이아웃·출장 약속
* 비용: 즉시 지출·계약 총부담·계약 후 연봉 여유
* 행동: 제안 또는 계약

회신도 거절 · 연봉 부족, **역제안 · 2년 3.5억**처럼 먼저 보여줘. 대리인 대사는 눌러서 읽게 하면 돼.

4. 계약 다음에 ‘팀이 좋아졌다’를 바로 느끼게

현재 계약 후 배치는 좋아졌어. 여기에 작은 변화 표시만 붙이겠어.

이선우 영입 완료
포수 백업 확보 ✓
벤치 배치　2군 배치

그리고 겨울 감독실의 포수 보강 과제도 동시에 완료돼야 해. 영입 화면에서는 완료인데 홈에서는 계속 보강하라고 하면 어색하니까.

개막 직전에는 올겨울 변화 한 화면:

* 영입 / 이탈
* 작년 라인업 / 올해 라인업
* 해결한 약점 / 남은 약점
* 개막전

계약한 선수가 팀에 들어온 모습까지 보여주는 게 영입의 보상이야.

5. 계속 하고 싶게 만드는 장치는 세 개만

장치	넣을 방식
영입 선수 첫 활약	첫 등판·첫 홈런 때 작은 소식. 영입 후 3경기 · 2승처럼 계약과 활약 연결
육성 선수의 자리 경쟁	2군 최근 활약 ↑ → 1군 백업과 비교 → 콜업을 한 흐름으로
겨울 계획 진행	선발 확보 ✓ · 포수 확보 ✓ · 재계약 2명처럼 내 팀이 완성되는 과정 표시

매일 억지 선택지를 만들지는 않겠어. 좋은 회신, 콜업할 만한 성적, 계약 만료처럼 실제 변화가 생겼을 때만 멈추고, 할 일 없는 날은 빠르게 넘어가게.

6. 모바일 화면은 이 규칙으로 고정

* 위: 지금 어디인지 + 핵심 자원
* 중간: 비교하거나 선택할 대상
* 아래: 선택한 대상 + 주 행동 버튼
* 긴 목록은 검색·필터·페이지로 처리
* 긴 설명은 **ⓘ나 상세**로 이동
* 색은 노랑=진행, 민트=선택·개선, 빨강=손실·위험
* 예산처럼 뜻이 넓은 단어는 무조건 줄이지 말고 **영입한도, 연봉여유**처럼 정확하게

내 작업 순서는 오류 수정 → 영입 메뉴 통합 → 비교·협상 간소화 → 계약 후 보상 → 시각 정리야.

지금 가장 필요한 건 새 콘텐츠 20개가 아니라, 선수 한 명을 고르고 데려와서 활약을 보는 과정 하나를 끝까지 기분 좋게 만드는 것이라고 봐.
