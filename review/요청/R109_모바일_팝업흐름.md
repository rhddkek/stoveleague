# R109 — 모바일: 버튼 → 아래에서 올라오는 창 → 다음으로 이어지기 (광우, 2026-11-13)

- 고른 범위: **세 곳부터** · 팝업 모양: **아래에서 올라오는 창**

## Claude가 휴대폰 폭(390)으로 새 게임(대구) 한 시즌 + 겨울을 해 보고 찾은 곳
1. 선수를 누르면 꽉 찬 상세 화면으로 넘어가고 ‹ 뒤로를 계속 눌러야 함
2. 겨울 「주요 업무」 6개가 각각 다른 화면으로 흩어져, 하나 끝내도 다음 걸 다시 찾아가야 함
3. 7경기 자동 · 시즌 끝까지 뒤 결과 · 멈춘 이유 · 다음 할 일이 띠 · 배너 · 창으로 제각각
4. 첫 화면 코치 추천 「2군 남도윤이 1군 김정우보다 낫습니다 DH C 58 ↔ C C 53」 — 지명타자와 백업 포수를 비교, 글자도 알아보기 어려움

## 만들 것
- 선수 카드 창(능력 · 이번 시즌 · 보직 · [라인업/보직][비교][상세]) — ‹ › 로 목록 넘기기
- 「하나씩 처리 ▶」: 할 일이 아래 창으로 하나씩, 처리하면 다음 일 · 다른 화면에 가 있으면 아래 알약 「할 일 n건 · 다음 ▶」 · 다 끝나면 「다음 주 ▶ / 경기 ▶」
- 경기 결과 창: 자동 진행이 끝나면 결과 + 멈춘 이유 + 「다음 목표」(연승 · 순위 차 · 기록 달성 직전) + [다음 경기 ▶][7경기 자동]
