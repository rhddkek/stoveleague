- 광우가 고른 것(4개 모두):
  1. 육성 앨범 — 해마다 지명 동기, 선수 연표(지명 → 데뷔 → 주전 → 올스타 → 해외), 「우리가 키운 선수」 표시
  2. 프랜차이즈 스타 — 칭호, 팬 인기 · 관중, 재계약 원클럽 할인, 떠나보내면 팬 반발, 은퇴식 + 영구결번
  3. 해외 진출 길 — 선수가 요청 → 구단이 허락하거나 거절 → 입찰 · 이적료, 진출 뒤 해외 성공 배지, 돌아오면 우리 우선
  4. 성장 연출 — 시즌 끝 육성 결산, 출전 기회 기반 각성, 멘토
