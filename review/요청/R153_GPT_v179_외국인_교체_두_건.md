# R153 GPT v179 플레이 — 외국인 교체 두 건

- 요청: 광우가 전달한 GPT 후기 (2026-11-18). v179 대구 저장 · 일반 외국인 · 아시아쿼터 각 한 명 교체
- 좋아진 점: 확정 단추 「궈 성안 방출 · 코디 해리스 영입」

## 항목
1. (1순위) 일반 호세 화이트(14억) → 마누엘 곤살레스(9.8억): 후보 목록은 연봉 −4.2억인데 확정 때 기존 여유 5.1억만 보고 예산 초과 → 이적 예산 15억을 돌려야 계약됨. 교체 후 여유 5.1 + 14 − 9.8 = 9.3억이므로 그대로 확정돼야 함
2. 아시아쿼터 FA 궈 성안 → 코디 해리스: 협상 화면 FA 영입비 3,805만 · 최종 확인 즉시 지출 6,300만(위약금만) · 완료 화면 약 1억. 확정 단추 위에 즉시 지출 1억 105만, 누르면 영입비 + 위약금 펼침
3. 배치 화면: 구원 투수인데 펼침이 「현재 선발 로테이션 보기」 → 불펜(보직)
4. 외국인 관리 하단 「외국인 4자리를 모두 채웠습니다 · 바꿀 때만 「교체」」 빼고 「투수진 보기」
