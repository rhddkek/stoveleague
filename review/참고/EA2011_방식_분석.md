# EA 프로야구 2011 — 게임 「방식」 분석 (2026-11-06)

플레이 영상이 남아 있지 않아, 광우가 가진 APK의 데이터 묶음(assets/data.vfs.mp3)과 실행 파일(libEA_BASEBALL2011MiAn.so)에 들어 있는 **도움말·메뉴·미션·중계 문구**를 읽어 구조를 복원함. 실행·인증 우회 없음. 원문은 참고만 하고 게임에 옮기지 않음(실명·문구 금지).

## 1. 전체 구조

| 모드 | 내용 (도움말 원문 요약) |
|---|---|
| 마스터 모드 | 유저가 팀을 골라 시즌을 치르며 **구단주·감독·선수 역할**. 한 시즌 133경기 |
| 마이플레이어 | 내 선수를 만들어 육성 → 다 키우면 **마스터 모드 내 팀 선수로 등장** |
| 대전 모드 | 다른 유저 팀과 친선·랭킹 대전, 「도발」 |
| 미니게임 | 내가 만든 선수로 홈런 더비·피칭 게임·배팅 연습 |
| 네트워크 | 선수 거래소, 친구에게 2군 선수 「특별 훈련」 맡기기 |

## 2. 마스터 모드의 방식

- **경기마다 진행 방식 고르기**: 「직접진행」(직접 치고 던짐) / 「감독모드」(작전만) / 「시뮬레이션」(결과만). 경기 전 「SET VS TEAM」 화면.
- **경기마다 미션**: 타자 미션·투수 미션이 따로 있고 단계별로 어려워짐.
  - 타자: 초구 안타 → 출루 1회 → 2안타 → 전 타석 출루 → 사사구 3 → 팀 8안타 → 홈런 → 희생타 3 → 기습 번트 안타 → 첫 타석 홈런 → 10안타 → 사이클링 히트
  - 투수: 첫 타자 삼진 → 무사사구 → 초구 스트라이크 → 무피홈런 → 6이닝 3실점 이하 → 병살 → 탈삼진 5 → 승리 투수 → 5이닝 → 3이닝 퍼펙트 → 한 이닝 3K → 9이닝 무실점 → 완투 → WHIP 1.00
  - 「미션 기간」 개념(여러 경기에 걸친 목표)도 있음
- **성장 = 경기 기록**: 「모든 선수들은 일정 시간이 지날 때마다 **자신의 경기 기록에 의해** 성장과 하락을 반복」.
- **예산**: 게임머니와 별개로 **연봉 계약에만** 쓰임. **시즌 성적이 좋으면 예산이 늘어남**.
- **팜(FARM) 투자**: 꾸준히 투자하면 즉시 전력 「슈퍼 루키」 발굴 확률. 도전과제 「팜관리 10시즌 연속 A등급」.
- **스토브리그 순서**(실행 파일 문구): 시즌 종료 → 포스트시즌 → 우승팀 → **구단 FARM 관리 → 1차·2차·3차 신인드래프트 → 용병드래프트(최대 2명) → 연봉협상(「계약 안 한 선수 일괄 계약」 버튼)** → 개막.
- **트레이드**: 시즌 중 언제나, **최대 2대2**, AI 구단이 **역으로 제안**. 「연차 적은 유망주는 트레이드 시장에서 환영받는다」.
- **코치 = 팀 스킬**: 코치마다 스킬 하나. 경기 중 발동(키 「*」), **30경기 동안** 효과(예: 파워 100 고정, 안타 확률 +20%, 헛스윙 +20%, 수비 실책 없음, 주자 주력 +10).
- **장비 아이템 = 맞교환**: 거의 모든 장비가 「하나 올리고 하나 내림」(예: R타격 +2 / L타격 −1, 파워 +2 / 주력 −10, 제구 +3 / 체력 −3). 「선수 특성에 맞춰 장착」이 핵심.
- **능력치 체계**: 타격 vs R / vs L 분리, 파워, 클러치(득점권), 선구안(코스 예측), 주력, 수비, 컨디션, 건강, 잠재력. 투수는 직구(포심·투심)·변화구·제구·체력.
- **능력치 도움말**: 능력마다 「무엇에 영향을 주는지 + 상성」 한 줄(예: 「구질 수치가 타자 타격보다 높으면 아웃 확률↑」, 「낮게 던지면 병살 유도↑ 대신 안타 확률도↑」, 「3루 도루는 웬만하면 포기」).

## 3. 몰입 장치

- **마이플레이어 이야기**: 고교 졸업 후 지명 실패 → 「이보게, 거기 ○○ 선수 아닌가?」 → **연습생** 입단 → 고된 훈련 중 감독이 「단기 목표를 가져보라」 → 명언 하나 고르기 → 이미지 트레이닝(한국시리즈 7차전 2아웃 만루 마무리) → **2군 리그 마지막 경기에 1군 코치들이 보러 옴** → 1군 러브콜. 육성이 끝나면 마스터 모드 내 팀에 합류, 도전과제 「마이 플레이어가 MVP 수상」.
- **중계 멘트**: 볼넷 하나에만 8세트 × 약 16문장. **점수 차·이닝·후반·우리 편/상대 편**에 따라 다른 말(「밀어내기로 한 점 추격」「오늘 경기 포기하나요?」「후반일수록 신중해야」). 경기 전 멘트(날씨·라이벌·연인 관중), 경기 후 멘트(한 점 차·대패·연장·무승부)가 따로.
- **도전과제 65개 + 칭호**: 「전설의 태동」「지도자의 첫 걸음」「기러기 감독(?)」「저주받은 손가락」 같은 재치 있는 이름. 첫 1승부터 100승, 기록·육성·실패(10점차 대패, 1회 선발 교체)까지.
- **역대 기록 비교**: 한국 프로야구 역대 시즌 기록(최다 홈런·최다 세이브 등)을 게임 기록과 나란히.
- **로딩 화면 명언** 27개(요기 베라, 매덕스 등).

## 5. 가져올 방식 (우선순위 제안)

1. **경기 미션** — 우리 경기마다 「오늘의 미션」 1~2개(우리 팀 기준: 선발 6이닝 3실점 이하, 무실책, 신인 첫 안타, 3점 이내 리드 지키기 등). 성공하면 작은 보상(팬·사기·성장 보너스). 단계가 올라가며 어려워짐. **결정 없는 날에도 매 경기 걸린 게 생김.**
2. **연습생 이야기** — 육성군에서 한 명을 「연습생」 주인공으로: 입단 사연 → 단기 목표 → 2군 마지막 경기에 1군 코치가 보러 옴 → 콜업. 우리 강점(서사)에 딱 맞음.
3. **중계를 상황별로 크게 늘리기** — 같은 결과라도 점수 차·이닝·우리/상대에 따라 다른 문장, 경기 전·후 멘트.
4. **코치 스킬 발동** — 시즌에 몇 번, 30경기짜리 효과를 감독이 「지금」 고르는 결정.
5. **성적 연동 예산** — 내년 예산이 올해 성적으로 정해짐 → 하위권도 마지막까지 승수가 의미 있음.
6. **도전과제 이름을 재치 있게, 수를 늘리기**(실패 과제 포함).
