# EA 프로야구 2011 (안드로이드) 분석 정리

- 작성: Claude · 2026-11-05 · 요청 R019-1
- 대상: 광우가 첨부한 APK. 게임 로직은 기계어(.so)로 묶여 있어 **앱 안의 한글 문구(약 1,700문장)와 도움말만** 읽었다.
- 원칙: **재미 구조만 참고한다.** 코드·수치표·그림·소리·선수명·구단명은 하나도 가져오지 않는다. 보호 장치는 건드리지 않는다.
  데이터 안에 실제 KBO 선수 이름이 들어 있어 그쪽은 손대지 않았다.

## 0. 이미 고친 것 — 구단명 충돌 (v32)
EA의 가상 구단 8개: 서울 팬더즈 · 안양 클론즈 · 수원 나이츠 · 인천 드래곤즈 · 대전 팔콘스 · 광주 캣츠 · 대구 라이거즈 · 부산 시걸즈.
우리 「부산 시걸스」가 똑같고, 「서울 팰컨스」는 애칭(Falcons)이 같아서 **서울 머스탱스 · 부산 돌핀스**로 바꿨다.
테스트가 이 8개 애칭과 겹치지 않는지 계속 확인한다.

## 1. 게임 구성 (메뉴 문구로 본 것)
| 모드 | 내용 |
|---|---|
| 마스터 모드 | 구단 운영 + 시즌. 경기는 「감독 게임(지시만)」 또는 「직접 실행(조작)」, 시뮬레이션 선택 가능 |
| 마이 플레이어 | 선수 한 명을 만들어 연습생 → 1군 콜업까지 키우는 이야기 모드 |
| 대전·네트워크 | 다른 유저 팀과 친선/랭킹 경기, 「도발장」, 유저끼리 선수 거래소·특별 훈련 보내기 |
| 미니게임 | 배팅 연습, 홈런 챌린지(10번 기회, 홈런이면 차감 없음), 투구 미니게임 |
| 상점 | 선수 카드·스카우트권·코치·장비·아이템 (유료 결제 포함) |

## 2. 구단 운영 시스템
1. **겨울 순서가 정해진 이벤트**
   「○○시즌 스토브리그 돌입 → 연봉협상 → 용병 드래프트 → 신인 드래프트 1차·2차·3차」를 차례로 진행.
2. **팜(육성 시설) 등급**
   「FARM 등급이 높을수록 좋은 신인이 발굴될 가능성이 높다」. 팜에 투자 → 등급(A~) → 신인 드래프트 후보 질.
   도전과제 「구단 팜관리 10시즌 연속 A등급」.
3. **신인 드래프트**
   1순위는 「우리 구단 팜」의 신인 중에서, 2·3순위는 「모든 구단 팜」에서 뽑는 3단계.
4. **용병(외국인) 드래프트**
   시즌마다 최대 2명 계약. 시즌 중 있던 용병도 드래프트에서 다시 재계약해야 함.
   용병은 1군에 있으면 드래프트 전에 2군으로 옮겨야 함.
5. **연봉 협상**
   선수가 「현재 ○억 ○천을 요구」 → 금액 입력 → 「승낙」 또는 「N차 거절」.
   「계약 안 한 선수 일괄 계약」 버튼. 예산이 부족하면 계약 불가.
6. **예산과 게임머니 분리**
   「예산은 연봉 계약에만 쓰인다. 시즌 성적이 좋으면 더 많은 예산을 지원받는다.」
7. **1군·2군 이동**
   「○○ 선수를 1군/2군으로 보내시겠습니까?」, 2군 로스터 슬롯 제한, 「RP 포지션만 2군으로 내릴 수 있다」 같은 제약.
8. **트레이드 (AI 판단 규칙이 문구로 드러남)**
   - 양쪽 「가치 점수」 비교: 우리 팀 최고 가치 선수 vs 상대 최저 가치 선수
   - 거절 조건: 트레이드 후 타자 9명 미만, 투수 6명 미만, 상대 포지션이 비는 경우, 로스터가 꽉 찬 경우
   - 플레이어에게 이유를 알려 줌: 「손해를 본다고 생각하는 것 같습니다」, 「포지션 문제로 불가능한 것 같습니다」
   - 도움말: 「연차가 적은 유망주들은 트레이드 시장에서 환영받는다」
9. **성장**
   「모든 선수들은 일정 시간이 지날 때마다 자신의 경기 기록에 의해 성장과 하락을 반복한다」.
   「잠재력 = 최대로 성장할 수 있는 수치」.
10. **코치(팀 스킬)**
    상점에서 코치를 계약하면 경기 중 쓰는 팀 스킬이 생김. 코치는 1명만, 바꾸면 이전 코치는 사라짐.
11. **컨디션**
    「컨디션이 좋지 않으면 제 실력을 발휘하기 어렵다」. 피로회복제 아이템.

## 3. 경기 쪽
- **작전 7종 + 이득/대가 한 줄 설명**
  | 작전 | 설명 |
  |---|---|
  | 번트 | 주자 있으면 보내기 번트 |
  | 히트 앤드 런 | 안타 시 추가 진루 / 아웃 확률 증가 |
  | 도루 | 주자 도루 시도 |
  | 이중 도루 | 주자 두 명 동시 도루 |
  | 고의사구 | 타자를 상대하지 않고 볼넷 처리 |
  | 볼넷 기다리기 | 볼넷 증가 / 아웃 확률 증가 |
  | 팀배팅 | 주자 진루 타격 / 장타 감소 |
  | (수비) 땅볼 유도 | 더블플레이 유도 / 장타 확률 증가 |
- **능력치 도움말**
  - 타격 L/R(좌·우투수 상대 따로)
  - 클러치(득점권에서 타격 향상)
  - 선구안(코스 예측)
  - 제구(장타 억제)
  - 「구질 수치가 타격 수치보다 높으면 아웃 확률↑」
  - 「좌투는 좌타에 강하다」
  - 「도루는 변화구 타이밍에」
- **중계 멘트**: 상황별(밀어내기·동점·역전·초반/후반) 해설 문장이 수백 개. 결과 + 상황 + 감정을 한 문장에 담는 방식.
- **투수 교체 AI**: 체력 저하 → 구원 / 마무리 등장 규칙.

## 4. 마이 플레이어(이야기 모드)
- 드래프트 마지막 순번에서도 지명받지 못한 고교 선수가 연습생으로 입단 → 「단기 목표를 가져보는 건 어떤가?」(코치)
  → 2군 리그 마지막 경기 → 1군 러브콜.
- **미션(주간 목표)**: 「한 경기 2안타 이상」, 「첫 타석 홈런」, 「희생타 3개」, 「평균 타율 3할」, 「사이클링(1·2·3루타·홈런)」…
  성공하면 「타자 파워 +2」, 「투수 제구 +2」처럼 능력 보상 (적용 기간: 다음 미션까지).
- 명언 고르기, 이미지 트레이닝 같은 짧은 분기 장면.

## 5. 도전과제 (예시 문구)
- 마스터 모드: 1승, 한 시즌 완료, 100승·200승, 홈런 100·300개, 탈삼진 100·300개, 도루 100개, 누적 타점 500
- 기록: 20연승, 완투승, 완봉승, 1군 선수 모두 출장
- 장난스러운 과제: 연장전 패배, 10점 차 이상 대패, 1회에 선발 투수 교체, 19연패, 수비 실책 50·100회
- 도전과제를 모두 깨면 최상급 아이템 오픈 + 보너스

## 6. 우리 게임에 쓰지 않을 것
카드 뽑기·카드 조합·조합실패 방지권·운명의 소포 같은 확률형 유료 아이템, 캐시 결제, 서버 저장, SMS, 유저 간 거래소.
우리 게임은 「작은 구단을 키우는 이야기」가 중심이라 확률형 수집 요소는 맞지 않는다.

## 7. 우리 방식 어레인지 → 반영 계획
| EA에서 본 구조 | 우리 방식 | 반영 |
|---|---|---|
| 겨울 이벤트 순서 | 겨울 화면 맨 위 「단계 띠」 (재계약 → 외국인 선수 → 신인 드래프트 → 동계 훈련 → 개막) | v35 |
| 팜 등급 → 신인 질 | 육성 시설·스카우트 투자를 「팜 등급」으로 묶어 드래프트 후보 질과 연결해 보여 줌 | v35 |
| 용병 드래프트 | KBO 2026 규정에 맞춘 **외국인 3명 + 아시아쿼터 1명**, 겨울 「외국인 선수 지명」 (재계약/방출 → 하위 팀부터 지명) | v33 |
| 신인 드래프트 3단계 | 보류였던 **5라운드 · 후보 80명 · 지명 후 계약** | v34 |
| 연봉 협상 N차 거절 | 재계약 화면에 요구액·제시액·몇 차 거절 + 일괄 재계약 | v35 |
| 트레이드 가치 판정 + 거절 이유 | 보류였던 **선수 교환 트레이드**. AI가 가치·포지션 공백·정원으로 판단하고 거절 이유를 문장으로 | v34 |
| 경기 기록 → 성장 | 이미 반영 (R017 성과 보너스) | — |
| 작전 7종 + 이득/대가 | 보류였던 **경기 작전**. 버튼마다 「이득 / 대가」 두 줄 | v34 |
| 도전과제 | 「구단 도전과제」 — 보상은 돈이 아니라 칭호·기록실 표시 | v35 |
| 마이 플레이어 미션 | 2군 집중 육성 선수에게 코치가 **단기 목표**를 줌 → 달성하면 작은 성장 보너스 + 콜업 추천 | v35 |
| 2군 리그 | 보류였던 **2군 실제 일정**: KBO 2026처럼 12팀(10개 구단 2군 + 군 팀 + 시민 구단), 북부·남부 6팀씩, 챔피언결정전 | v33 |
| (EA엔 없음, 광우 요청) | **올스타전**: 청팀·홍팀, 베스트 12(팬 투표 70% + 선수단 투표 30%) + 감독 추천 13명씩 | v33 |
