# EA 프로야구 2011 — APK·실행 시도 현황 (다시 묻지 않도록 기록)

- APK: 광우가 2026-11-05·06에 첨부함 (`EA프로야구2011.zip`). 이미 풀어서 그림 조각 약 1,000장 + 한글 문구 약 1,700문장 추출 → `EA2011_분석.md`, `EA2011_방식_분석.md`
- 화면 배치(좌표·글자)는 실행 파일 `lib/armeabi/libEA_BASEBALL2011MiAn.so` 기계어 안에 있음 → 파일로는 완성 화면이 안 나옴. 실행 화면 캡처가 필요
- **T스토어 인증은 문제 아님** (GPT·광우 확인, 블루스택 로그도 인증 뒤 GLThread에서 튕김)
- 실패 원인 = 칩: APK에 `armeabi`(옛 ARM 32비트) 코드만 있음
  - 블루스택(x86, ARM 변환): GLThread에서 SIGSEGV (변환 계층 libtcb.so)
  - Android Studio Nexus 4 + 7.1.1: x86 이미지라면 ARM 변환 기능 없음 → 안 됨
- 다음에 해 볼 것: ① Android 11(API 30) x86 이미지(ARM 변환 포함) ② armeabi-v7a 옛 이미지 ③ 옛 안드로이드 폰
- 켜지면: 감독모드 화면 캡처 → 배치·흐름만 분석해 스토브리그용으로 새로 그림 (EA 그림·문구는 사용 금지)
