# EA 프로야구 2011 — 원작 화면·판정 복원 (2026-11-07, Claude)

실행 파일을 ARM 에뮬레이터로 직접 돌려 원작 코드가 원작 그림·글꼴로 그린 실제 화면을 얻었다(도구: `ea2011_도구/`). 화면 이미지가 들어간 보고서(`EA2011_원작화면_복원.html`)는 EA 저작물이라 저장소에 넣지 않고 광우에게만 전달했다. 여기에는 결론만 적는다. 그림·문구는 스토브리그에 쓰지 않는다.

## 스토브리그 흐름
스토브리그 돌입 → 연봉협상 → 용병드래프트 → 1·2·3차 신인 → FARM 관리 → 개막. 단계마다 검은 안내 화면 한 장(「2011 Stove League · 2011 시즌 ○○」 OK NEXT).
연봉협상은 전원 계약해야 끝난다(방출 없음). 「전체계약」(#) = 남은 선수 요구액대로 일괄 계약 → 바로 용병 단계. 확인창에 총액·남는 예산 표시 없음.

## 연봉협상 판정 (`MS_StoveMoneyAI`, 코드 해석 + 실측 일치)
- 기준선 = 요구액 − ⌊요구액×5×r/100⌋, r = 1~4 무작위. 제시 ≥ 기준선이면 수락 → 요구액의 95% 이상 항상 수락, 80% 미만 항상 거절.
- 1차 거절: 요구액이 조금 내려감(예 2억8천 → 2억7천). 2차 거절: 요구액 원복 + 「협상」 메뉴 꺼짐 → 요구승낙만.
- 오버롤 75 이상 + 성장 수치 높은 선수: 요구액 100%만 수락.
- 협상 입력: 억·천 자리 ▲▼, 구단운영비가 입력 즉시 바뀜.

## 용병·신인·팜
- 용병: 메뉴는 선수정보/계약뿐, 요구액 그대로 계약 → 즉시 2군 등록.
- 신인 1차 = 우리 팜 3명 중 1명, 2·3차 = 모든 구단 팜, SKIP 가능, 계약 → 2군.
- FARM: A~D 등급 5,000/4,000/3,000/2,000 볼, 「등급이 높을수록 좋은 신인 발굴 가능성」.

## 트레이드 (1대1 56건 실측)
- 거절 이유 2가지: 손해(가치) / 포지션(상대 수비 구성). 포지션 검사가 먼저.
- 상대가 받는 선수 오버롤이 더 높아야 성사(같으면 거절). 예외: 포수 80은 83과도 안 바꿈(오버롤 외 보정).
- 거절되면 제안 칸이 비워짐(EA 약점).

## 스토브리그 적용 후보 (R053)
- 단계가 바뀌는 주에 한 장짜리 단계 안내.
- 협상: 「첫 거절 → 요구 소폭 하향, 두 번째 거절 → 기회 끝」을 화면에 명시. 95%/80% 같은 확률 구간 안내.
- 트레이드 거절 이유 한 줄(손해/포지션), 거절돼도 제안 유지.
