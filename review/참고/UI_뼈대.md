# UI 뼈대 (v60 기준) — 모든 화면이 따르는 원칙

광우 지적(「다 따로 놀고, 타고타고 들어가야 보인다」)에 맞춰 세운 큰 틀. 새 기능·화면을 넣을 때 이 문서부터 맞춘다. 벤치마킹: FM 모바일(목록 한 줄 → 선수 메뉴), 클럽스토리(필터 칩·할 일 보드), EA 2011(한 화면 = 한 결정).

## 0. 겉모습 (v63, GPT 개편안)
- 크림 바탕 · 짙은 슬레이트 상·하단 바 · **주황 하나**(진행 버튼·선택 탭·제목 세로줄). 섹션 제목 「▍제목」.
- 선수 목록은 **표 + 아래 조치 바**(상세 · 보직/라인업 · 1군↔2군 · ⋯). 카드 보기는 보조.
- 하단 탭 **6개**: 감독실 · 선수단 · 육성 · 이적 · 리그 · 구단. 시안 원본 `review/참고/GPT_UI안/`.

## 1. 탭 안은 칩 3개 + 더보기
| 탭 | 하는 일 | 칩(핵심 3) | 더보기 |
|---|---|---|---|
| 감독실 | **오늘 할 일** — 다음 경기·결정·스토브리그 할 일 보드 | — | 소식·시상·점검 |
| 선수단 | 우리 선수 보고 **배치** | 선수 / 라인업 / 투수진 | 2군·임대, 성장, 훈련 |
| 영입 | 남의 선수 보고 **데려오기**, 내 선수 **내보내기** | 제안·협상 / 선수 찾기 / 트레이드 | 판매 등록, 드래프트, 외국인, 스카우트, 유소년 |
| 리그 | 순위·일정·기록 (보기만) | 순위 / 일정 / 기록실 | 2군 리그·명예의 전당·역대·도전과제 |
| 구단 | 돈·시설·위상·설정 | 재정 / 시설 / 위상 | 스폰서·코치·설정·데이터 |

- 탭에서 **두 번 누르면 조치**가 나와야 한다(탭 → 칩 → 줄 끝 버튼). 세 번 이상 들어가야 보이는 조치는 뼈대 위반.
- 설명 문장은 기본 접힘(「설명 보기」). 숫자·버튼이 먼저.

## 2. 선수는 어디서 보든 같은 한 줄
`얼굴 · 이름 · 포지션·나이 · [상태 칩] · 한 줄 정보 | 등급 종합 (변화) / 잠재 | [바로 버튼] ⋯`

- **우리 선수**: `squadRow()` → ⋯ = `pmenu()` (선수 정보·라인업·보직·집중 육성·1군↔육성군·임대·판매·재계약·훈련·관심)
- **남의 선수**(타 구단·FA·드래프트 후보·외국인): `mrow()` → ⋯ = `mmenu()` (선수 정보·영입 제안/FA 협상/지명·우리 같은 포지션과 비교·관심)
- 그 화면의 **가장 흔한 조치는 줄 끝 바로 버튼**(`.act1`): 선수 찾기=제안, FA=협상, 드래프트=지명, 재계약=협상, 판매=등록/해제, 협상 중=테이블로.
- 오른쪽 둘째 줄은 기본 「잠재」. 그 화면에서 더 중요한 숫자가 있으면 바꾼다(재계약 → 요구 연봉).
- 표로 보기(`lmBtn`)는 보조. 기본은 카드(줄).

## 3. 결정은 「할 일」로 모은다
- 시즌 중: 감독실 오늘 카드에 **결정할 일**(선발 교체·대타·훈련 방향·코치 제안) → 한 줄에 선택지 버튼 2개. 경기마다 미션 1~2개.
- 스토브리그: 감독실 **할 일 보드**(이번 주 마감 / 진행 중 / 다가오는 일 / 완료). 각 항목은 **그 조치가 있는 화면으로 바로** 간다.
  - 재계약 협상 → 영입·협상 중(계약 만료 목록 + 협상 버튼 + 일괄 재계약)
  - 신인 지명·신인 계약 → 발굴·드래프트(계약 대기는 맨 위 카드)
  - 겨울리그 파견 → 성장·겨울 / 외국인 지명 → 발굴·외국인 / 스폰서 → 감독실 결정 / 동계 훈련 → 성장·훈련
- 「다음 주로」 버튼은 항상 같은 자리(감독실 큰 버튼). 건너뛰면 자동 처리되는 것을 먼저 보여준다.

## 4. 화면 하나 = 목적 하나
- 라인업: 다이아몬드 + 9칸. 칸 누르면 후보 목록(적성·교체 대상 표시).
- 투수진: 투수 전부 한 목록, 보직 칩(선발/롱/셋업/마무리/불펜)으로 바꾼다.
- 협상: 상대 얼굴 작게, 대화 밑에 입력, 빠른 버튼(요구 −10% / 요구대로 / +10%).
- 선수 상세: 능력 육각형 + 종합 숫자, 비교 기준 선택. 조치는 여기서도 ⋯와 같은 메뉴.

## 4-1. 선수단 구조 (v61)
- **1군 엔트리 26명 고정** (라인업 9 · 선발 5 · 마무리 · 불펜 · 벤치). 경기에 나가는 건 엔트리뿐.
- **선수단(2군)은 상한 없음**, 육성군은 시설 수만큼. 2군 = 엔트리 밖 선수단 + 육성군 → 퓨처스 경기.
- 올리고 내리기는 어디서든 ⋯ 한 번: 「1군 등록」(가득 차면 내릴 선수 고르기) / 「1군 말소 → 2군」.
- 부상은 자동 말소·보충, 복귀는 원래 자리. 「다음」 버튼은 상단 구단 바에 항상.

## 4-2. 겨울(스토브리그) 구조 (v62, FM 방식)
- 감독실 = **겨울 과제**: 지난 시즌 원인 → 전력 이탈 → 보강할 자리 → 예산 → 추천 후보 → 영입 후 변화. 5주차부터 **겨울 결산**.
- 돈은 **구단주 예산** 두 칸(연봉·이적). 구단 자금이 많아도 예산을 넘는 계약은 막힘 → 「누구를 잡고 누구를 포기할까」.
- 시장 셋은 다른 맛: **FA**=경쟁 입찰·결정 주 / **해외·외국인**=스카우트 지식도로 찾기·이적 합의금 / **신인**=시즌 중 관찰 명단·예상 순위.
- 해외 선수 능력은 어디서든 **같은 추정 범위**(지식도). 우리 선수·국내 선수만 정확한 숫자.
- 계약 = 끝이 아니라 **배치 제안**까지.

## 5. 아직 뼈대에 못 맞춘 곳 (다음 순서)
1. 트레이드: 양쪽 고르기 화면을 같은 줄 + 바로 버튼으로.
2. 외국인 지명·스카우트·유소년 목록을 `mrow`/`mmenu`로 (지금은 자체 줄).
3. 구단 탭: 시설을 격자 카드, 재정·위상을 게이지 한 장으로.
4. 리그 탭 일정에서 「다음 경기」 바로 가기.
