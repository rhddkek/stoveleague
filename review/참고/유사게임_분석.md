# 유사 게임 분석 — UI와 중독성 (2026-11-06)

조사 범위: 앱스토어·구글플레이 설명과 공개 리뷰, 펨코 「단장 시뮬」 글 제목, OOTP 개발자 인터뷰·비평 글. 직접 플레이한 건 아니므로 「설명·리뷰로 읽히는 범위」임.

## 1. 경쟁작 개별 분석

### 클럽스토리: 야구 매니저 (NBstudio) — 가장 가까운 경쟁자
- 규모: 구글 1만+ 다운로드, 평점 4.8(634개), 2026-10 업데이트, 인앱(확률형 포함), 한·영·일.
- 구조: 가상 24구단 3부 승강제 84경기 → 1부 우승 → 국가대표 감독(8개국 국가대항전) → 10시즌 뒤 「커리어 대전」(다른 유저와 리그). 랭킹 대전·티어·레전드 구단 등재.
- UI (캡처 기준):
  - 하단 탭 3개(팀관리 · 대시보드 · 구단운영)로 극단적으로 단순. 팀관리 안에 타자/투수/작전 세그먼트.
  - 타순 = 다이아몬드 위 얼굴 카드, 밑에 교체 명단 가로 스크롤. 숫자 한 개(종합)만 크게.
  - 경기 = 점수판 → 투수 능력 6개 두 줄 → 2D 구장에 선수 도트 → 타자 능력 6개 → 중계 한 줄 → 속도 ×0.5/×1/×2.
  - 시설 = 그림 8칸 그리드 + 「완벽 ★★★★」 상태. 글자가 거의 없음.
  - 드래프트 = 목록 + 「상세보기」「+」 두 버튼, 상단에 라운드·픽 진행 막대.
- 리뷰에서 읽히는 것:
  - 칭찬: 「간단해 보여도 속은 자세」「육성 시스템」「FA가 있다」「난도가 만만치 않다」「업데이트가 열정적」.
  - 불만: 「한 팀만 계속 우승해 재미 반감」(AI 구단 리빌딩 부재), 「타 팀 가을야구 성적·은퇴 선수 기록을 보고 싶다」, 「조작이 익숙지 않아 2부로 떨어짐」(초반 학습).
  - 개발자가 모든 리뷰에 답글. 「데이터 용량 때문에 은퇴 선수 전부 보관 어렵다」 — 우리는 이미 해결(기록 배열 압축, 명예의 전당).
- 중독 장치: 승격/강등(매 시즌 걸린 게 있음), 티어, 국가대표 제의(장기 목표), 커리어 대전(10시즌 뒤 보상), 확률형 선수 카드.

### 펨코 「단장 시뮬」 물결 (개인 여러 명, 2026)
- 「프로야구 단장이 되어보자」 1.4→1.5, 「KBO 프로야구 단장 웹 시뮬레이터 v2.0」, 「KBO GM Simulator(FM 스타일 리마스터)」, 「10개 구단 1,052명 전체 로스터 DB」, 걸그룹 리그 시뮬까지.
- 공통: 브라우저 단일 파일, AI로 제작, **실명 KBO 선수**, 드래프트·트레이드 중심, 커뮤니티에 올리고 피드백 받아 버전 올림. 우리와 제작 방식이 똑같음.

## 2. 매니저 게임의 중독 구조 (공통점)
1. **짧은 루프에 결정이 하나씩** — 「경기 하나 → 결과 → 작은 결정(교체·훈련) → 다음」. 결정 없이 넘기는 날이 이어지면 이탈.
2. **항상 걸린 게 있다** — 승격/강등, 순위 싸움, 목표 미달 시 경질, 시즌 패스. 「지금 지면 뭐가 어떻게 되는지」가 매 경기 보여야 함.
3. **숫자가 눈앞에서 오른다** — 성장 점검, 카드 강화, 시설 별. 변화가 보이지 않는 성장은 없는 것과 같음.
4. **장기 목표가 겹겹이** — 이번 경기 / 이번 주 / 시즌 / 커리어(국가대표, 명예의 전당, 레전드). 하나 끝나면 다음이 보여야 함.
5. **내 선수에 정이 든다** — 실명(컴투스·펨코)이거나, 가상이면 얼굴·서사·기록(OOTP·클럽스토리).
6. **커뮤니티로 돌아옴** — 펨코 포텐, 랭킹 대전, 리뷰 답글.

## 4. 더 잘 만들려면 — 우선순위

### A. 중독성 (게임 쪽)
1. **매일 결정 하나 보장** — 날마다 「오늘의 결정」 1개를 홈 맨 위에: 선발 교체 제안, 2군 콜업 추천, 트레이드 문의, 코치 건의 중 하나. 넘기면 코치가 알아서 하고 결과만 보고.
2. **8월 이후에도 걸린 것** — 가을야구 탈락 팀에게: 신인 출장 목표(「유망주 3명 100타석」), 구단주 과제, 다음 시즌 드래프트 순번 싸움, 내년 예산 산정(시즌 성적·관중 연동). 승강제는 리그 구조상 안 넣음.
3. **장기 목표를 첫 화면에** — 「커리어」 띠 하나: 현재 단계(지방 구단 감독) → 다음(가을야구 3회 / 해외 구단 제의 / 명예의 전당 헌액 선수 배출). 진행률 표시.
4. **성장 점검 주기 단축 + 눈에 보이게** — 2주 → 1주, 변화가 있으면 소식 띠에 얼굴과 함께 「+1」.
5. **시즌 마무리 연출** — 시상식·결산·「올해의 우리 선수」 한 장 카드(공유용 이미지).

### B. UI (화면 쪽)
1. **글자 → 그림**: 시설 탭을 도트 건물 그리드로, 구단 위상·재정을 게이지로.
2. **경기 기본값을 「장면」으로**, 처음 한 경기만 「타석」 안내.
3. **홈 = 오늘의 결정 1개 + 다음 경기 버튼 + 커리어 띠**. 나머지는 밑으로.
4. **선수 상세 첫 화면 = 얼굴 크게 + 육각 + 한 줄 평**, 표는 탭 뒤로.
5. **첫 시즌 안내를 「해 보기」로**: 글 대신 실제 화면에서 손가락 표시 한 번씩.

### C. 배포·커뮤니티
1. 펨코·디시 야구 갤에 「가상 리그라 실명 없음, 설치 없음」을 장점으로 내세워 공개 → 피드백을 요청서(R번호)로 받는 지금 체계가 그대로 쓰임.
2. 공유 카드(시즌 결산 이미지)로 입소문.

## 5. 한 줄 포지셔닝 (제안)
**「설치 없이 링크 하나로, 가상 선수와 10년을 같이 보내는 야구 단장 인생」** — 실명 시뮬(펨코·컴투스)과도, 뽑기 카드(9UP·OOTP 퍼펙트 팀)와도 다른 자리.
