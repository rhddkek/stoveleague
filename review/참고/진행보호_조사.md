# 진행 보호 · 계약 정리 — 다른 게임 조사 (v68 근거)

광우 요청 「FA 같은 건 무조건 확인하고 넘길 수 있게」에 맞춰, 같은 장르 게임이 **큰 손해가 나는 진행을 어떻게 막는지** 확인하고 그대로 옮겼다.

| 게임 | 방식 | 스토브리그 적용 |
|---|---|---|
| Football Manager (FM24 매뉴얼 「Inbox and News」, FM21 「The User Interface」) | 답해야 할 메시지가 있으면 오른쪽 위 **Continue 버튼이 「Must Respond」로 바뀌고** 눌러도 시간이 가지 않음. 누르면 그 메시지로 이동 | 상단 「▶ 진행」이 **「⚠ 확인 N」(빨강)** 으로 바뀜. 누르면 바로 넘어가지 않고 확인 창. 감독실 하단 큰 버튼도 빨강 + 「확인할 일 N건」 |
| FM | 평소 진행은 바로, 꼭 결정할 것만 막음 | 확인 창은 **재계약 마감(2주차 → 3주차)·개막(만료 선수·미계약 신인)** 때만. 나머지 주는 그대로 진행 |
| OOTP Baseball (위키 「Building a contract offer」 · 「After the contract offer」) | 제안을 만들면 **Meet Demand / Ask for Response**로 선수 반응을 먼저 확인, 역할(주전) 약속 포함 | FA 협상 화면에 **① 개인 요구 충족/미달 ② 경쟁 제안보다 앞섬/부족**을 나눠 실시간 표시. 선수가 실제로 비교하는 점수(faScore)와 같은 계산 |
| OOTP · Sports Mogul 계열 | 만료 계약 목록에서 **한 화면에 일괄 처리** | 이적 → 계약 관리 → 재계약: 유지 / 협상 / 결별 한 줄씩 + 「추천대로 채우기」 + 「결정 실행」 |
